# Research log — 2026-10-25

## Purpose

最適化したい目的を campaign 内で固定し、その目的を最もよく実現する科学システムを探索する。変更対象は制度パラメータ、機構、将来的には制度構造そのものであり、観測後の目的定義ではない。

## Implemented

- frozen Metric Constitution を各 completed run に適用する objective evaluator を追加した。
- hard constraints、capability constraints、未集約 objective vector、比較可否を `objective_evaluation.json` に保存する。
- evaluator version と implementation hash、run provenance を保存し、同じ evaluator producer で比較したことを検査可能にした。
- design ごとの反復数、metric summary、ranking authorization と blocking reason を harness report に追加した。
- protected slice を artifact から正しく構成できない場合は、推測値を作らず `unknown` とする。

## Decisions

- optimization campaign 中は objective、constraints、evaluator を固定する。
- activity や funding diagnostics を、便宜的に objective へ昇格させない。
- run 終了時 funding quantile から protected slice を逆算しない。outcome-conditioned selection になるためである。
- 現行 revision の残り 8 runs は sensitivity exploration と実装検証に使えるが、measurement-complete な制度ランキングとは呼ばない。
