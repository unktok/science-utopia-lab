# Research log — 2026-10-25

## Purpose

最適化したい目的を campaign 内で固定し、その目的を最もよく実現する科学システムを探索する。変更対象は制度パラメータ、機構、将来的には制度構造そのものであり、観測後の目的定義ではない。

## Implemented

- frozen Metric Constitution を各 completed run に適用する objective evaluator を追加した。
- hard constraints、capability constraints、未集約 objective vector、比較可否を `objective_evaluation.json` に保存する。
- evaluator version と implementation hash、run provenance を保存し、同じ evaluator producer で比較したことを検査可能にした。
- design ごとの反復数、metric summary、ranking authorization と blocking reason を harness report に追加した。
- protected slice を artifact から正しく構成できない場合は、推測値を作らず `unknown` とする。

## Measurement-complete revision

同日、集計値だけを増やすのではなく protected slice を直接評価できる instrumentation を追加した。

- `population_resource_profile=balanced_two_band` は run 開始時に seed から lower/upper band を固定する。
- smoke population 10 人では lower 5 人に 50、upper 5 人に 150 を割り当て、総初期資源 1000 と平均 100 を維持する。
- `agent_year` は固定 band と initial funding を保持する。
- `review_action` は reviewer、paper、conference、year、score、reviewer band を 1 action 1 row で保持する。
- checkpoint resume 後も band と initial funding を agent state に保持する。
- evaluator 1.1 は action 総数を checkpoint aggregate と照合し、最低 slice support 5 を検査する。
- aggregate が floor を満たしても protected slice が floor 未満なら candidate は infeasible になる。
- evaluator version と Constitution version が一致しなければ評価を拒否する。

新しい `study-v1-smoke.json` は objective evaluator 1.1 に結び付いた Constitution 1.1、5 exploration seeds、5 designs を持つ。v0 の残り run は異なる producer version と混ぜず、historical sensitivity evidence として凍結する。
