# Lab log — 2026-10-24

## 今日の目的

1. 論文 *Science Utopia? Closed-Loop LLM Simulation of Academic Research Ecosystems* の公開実装をローカルで動かす。
2. 今後の制度最適化研究を、再現可能な研究プロジェクトとして開始する。

## 実施

- 上流 `Ahren09/ScienceUtopia` を取得。
- Apple Silicon では vLLM/CUDA 経路を使えないため、OpenAI互換APIを持つ Ollama backend を追加。
- `qwen3:8b` を取得し、LLM推論が Metal GPU 上で動くことを確認。
- structured outputs を Ollama の `response_format` へ変換。
- embedding / RAG の device を設定可能にした。
- MPS 上の retrieval は unified memory の高水位エラーが起きたため、LLMをGPU、RAGをCPUとする安定構成を採用。
- macOS上の互換性のため NumPy 2.4.6、SciPy 1.17.1 を選択。
- 2機関・10研究者・1年の実モデル run を完走。
- 研究憲章、抽象モデル、最適化計画、ゲーム構想、roadmap、実験テンプレートを作成。

## 観察

- Qwen3-8B は Ollama 上で約11 GBを使用し、推論処理は100% GPU表示だった。
- 1機関だけでは、自機関の論文を査読できない制約により reviewer pool が成立しない。最小の有用な smoke topology は2機関である。
- 最初の成功 run は約27分。最適化ではこのコストが支配的なので、低 fidelity、response cache、並列実行、代理モデルが重要になる。
- 1 run の結果だけでは目的関数のノイズも制度効果も評価できない。次は反復可能な harness が必要。

## 追記 — Design Space v0

- 現行CLIと計測テーブルを監査し、最初の設計空間を8変数へ限定した。
- 採択率、review数、reviewer容量、matching、review policy、固定資金枠、申請費用、再投稿費用を選んだ。
- 採択数は制度自身が直接操作できるため、primary objectiveにしないと決めた。
- topic breadth、submission novelty、研究者維持、資源公平性、review burdenを未集約の5目的とした。
- 現行系に科学的ground truthがないことをmajor measurement gapとして記録した。
- 機械可読JSON、候補validator、既存CLIへの変換を追加した。

## 追記 — Seed-replicated harness

- 指標定義と実行管理を分離した。
- baseline + random/Sobol designを複数seedへ展開するplannerを追加した。
- exploration、selection、confirmation seedを互いに素な集合として仕様化した。
- SQLite run registry、決定的run ID、attempt log、checkpointを維持するretryを追加した。
- exit codeだけでなくnative run manifestのcomplete状態を成功条件とした。
- operational reportは活動量と実行時間だけを扱い、最適化目的とは明確に区別した。

## 追記 — 科学政策との接続

- 研究システムの良さを測ることは、国家が科学政策で何を目指すかという目的設定に近いと整理した。
- ただし国家を唯一の効用主体とはせず、科学者、市民、将来世代、国際的knowledge commonsを分離する。
- epistemic value、scientific capacity、public/mission value、distribution/legitimacy、constitutional constraintsの階層を導入した。
- 学問の自由や最低限の公平性は、成果と交換するpenaltyではなくhard constraintになりうると記録した。

## 追記 — 目的関数の文献調査

- Science of Science / metascienceの一次資料と、`ai-scientist-survey`内の12資料を別々のsubagentで調査した。
- 両調査が、hard constraints、能力保存、commitment別多目的、目的・評価器のgovernanceという四層へ収束した。
- v0 metricを科学的価値のprimary objectiveから、pipeline検証用の暫定proxyへ位置づけ直した。
- noveltyとresource equalityを無条件に単調最大化しないと決めた。
- claim/version/evaluator relationを評価単位とし、evaluation、decision、allocation、appeal/correctionを分離する方針をADR-0002に記録した。
- Apple同梱Gitを実行できない環境でもrun manifestがcommitを失わないよう、Git metadataからHEADを読むprovenance fallbackを追加した。
