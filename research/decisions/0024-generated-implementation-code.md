# 0024 — Generate implementation code, not just numeric expressions

Date: 2026-10-31

The user correctly identified that a fixed numeric AST remains a narrow
institution grammar. Extend breadth before adding seeds or budgets.

Add a separate code-backed mechanism implementation to the generic SystemSpec
runtime. A local LLM writes actual Python, internal JSON memory, and new
artifact payload schemas; the host requires only compatibility contracts.
Execute source only in bounded, local no-network Docker containers, never host
Python or a browser. Preserve model requests/responses, image/source/context/
result hashes, canonical events, and checkpoint evidence.

Use a two-period paper fixture and the production PaperTracker to establish
the executable vertical slice. Measure scalar loss on the host, feed actual
observations to code revision, and permit degenerate all-accept/all-reject
solutions under deliberately trivial opposing objectives. No hidden policy
veto or manually favorable fallback is introduced.

Do not claim that arbitrary generated code is automatically differentiable,
that extra artifact storage creates a fully operating institution, or that
this fixed graph harness integrates every mechanism with the original live
Qwen researchers. Inventory these non-scale gaps explicitly in
`research/audits/non-scale-limitations-v1.md`.
