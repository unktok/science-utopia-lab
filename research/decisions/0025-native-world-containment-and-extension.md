# 0025 — Contain and extend the research world, do not simplify it away

Date: 2026-10-31

The user clarified that even the original ScienceUtopia world is too simple.
It must be contained as one instance of a more expressive architecture, not
replaced by a simpler numeric model and not installed as the architecture's
ceiling. More actors/artifacts/behaviors/processes must remain extensible.

Implement the generic mechanism executor against live Simulation phases and
domain objects. Preserve existing model prompts and state transitions in the
baseline configuration. New institutions communicate through explicit typed
ports and affect actual native researcher inputs and lifecycle state. Preserve
cross-period memory, queues, provenance and checkpoint/resume.

The numeric miniature is retained only as method testing. Native-world
differentiation must identify opaque/discrete nodes and tie approximation and
validation to native trajectories; a differentiable replacement toy does not
satisfy this goal. See `components/native-science-kernel-v1.md`.
