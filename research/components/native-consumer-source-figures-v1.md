# Matched-search paths and literal outcomes: prepared, not rendered

The [original matched pilot](../protocols/campaigns/native-consumer-source-comparison-v1.md)
is running separately from immutable7e51b2a4. Its loss, world, author authority,
budgets and selections are not changed by this analysis module.

[`native_consumer_source_figures_v1.py`](../../scripts/reports/native_consumer_source_figures_v1.py)
prepares two views of the original all-slot report:

1. U/C panels containing both information arms, each actual proposal, best own
   submitted loss and best known loss including the visible parents. Both visible
   references and the known withheld terminal hand control remain labeled.
   The withheld hand result is not silently inserted into the known incumbent.
2. All three references and all eight own slots, including nulls, with T/U/C,
   collected cost, unpaid cost and requested expense. Unknown is not zero;
   requested expense is diagnostic, not a replacement objective or a veto.

The pure projection retains declared selection/contrasts and exact original
readout/scientific identities. It checks literal path arithmetic, visibility,
own selection and collected-plus-unpaid accounting, and never executes a model,
world or generated program. A selected-loss difference is not an isolated
source-comprehension effect, independent search replication or scientific truth.

The CLI requires the actual original readout continuation to have normally
closed, both original three-file exports to match its hashes, their manifests
to agree and its frozen reader to match the recorded source. A prepared plan
or a currently waiting readout is not enough. Exports must be fresh and outside
the original readouts and both source checkouts. `--render` is opt-in; without
it the module exports only `report.json`, `outcomes.csv` and `manifest.json`.

After normal original closure, invoke the module from a clean committed analysis
source, passing the actual readout continuation directory and original frozen
reader. Export twice, compare all resulting bytes, then inspect both PNG/SVG
figures and their labels/layout before retaining them in the paper. No figure
is currently rendered or visually verified. No figure/PDF generation or heavy
integration test is run alongside the actual model inference.

The [pure preparation receipt](../results/native-consumer-source-figure-preparation-v1.json)
records11 SCRIPTED data/closure/export tests in1.19s. The initial source-local
output fixture fails before export, despite nine other passing tests. Its JUnit
is retained; the new fixture uses an external temporary directory and a separate
test verifies that the source-local production guard still rejects output.
Project instructions now state this distinction explicitly. These tests do not
render images, run an original cold audit or measure actual model outcomes.
