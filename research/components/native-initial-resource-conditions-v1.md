# Explicit native initial resource conditions

The native factory now accepts an optional operator-owned `world_conditions`
contract containing positive finite `initial_funding`, the original `equal` or
`balanced_two_band` population profile, and a Boolean resource-ledger flag.
These values reach the existing Simulation arguments and population blueprint;
research, costs, grants, projects and activation rules are not replaced.
Candidates do not supply or rewrite this experiment configuration.

When omitted, the original argument list and scientific binding fields are
preserved. An explicit condition is copied and bound into the response-cache
science configuration. Cold physical proof compares the actual founder IDs,
resources, initial resources, resource bands and active flags with the original
seeded blueprint, and verifies ledger presence. Metadata alone cannot certify
the condition. Conservation and scientific merit are different concepts; this
interface adds no participation or fairness veto.
