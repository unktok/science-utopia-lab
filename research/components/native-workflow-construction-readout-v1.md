summarizer. It does not change the runningf47270b9 science source, designer
messages, loss, choices, probe budget, source or selection. It is not itself
an original-source audit or a new experiment.

After normal six-slot closure and two matching original-source audits, run:

```

  --run ORIGINAL_RUN --audit-one ORIGINAL_AUDIT_1 --audit-two ORIGINAL_AUDIT_2 \
  --output FRESH_EXTERNAL_OUTPUT
```

The reader requires the original unchanged raw inventory and exact six
objective/generation joins. It binds each actual staged wrapper/request/
definition and original inner response/steps, then reports component probe
offsets/totals, returned/raised observations, same-fixture later-code changes,
configured/unconfigured and budget-exhausted notices, and final literal
artifact applicability. Every slot keeps its graph edits, native completion
or null, both losses and original own-only selection. Missing known-null
terminal evidence stays unknown, not a manufactured zero or finish. Existing
native loss-path and full-input reports stay separate and unchanged.

An observed raised-to-returned transition is not proof that diagnostics caused
repair, that the return is scientifically good, or that the native world runs.
A later untested artifact does not inherit an earlier suite's result. Steps,
fixtures and probes are not independent optimizer histories. Calibration calls
are not proposal attempts. No extra veto or scoring criterion is introduced.

the original audit/cost chain and export this view twice. It runs from its own
clean frozen analysis worktree, never by changing active scientific or reader
sources. It makes zero new model calls/code executions/native worlds and
writes only outside the raw run. It can start waiting while inference is live;
actual inventory/export work begins only after normal audit closure.
