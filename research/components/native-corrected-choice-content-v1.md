# Corrected signed-content readout: data-only preparation

The [new reader](../../scripts/reports/native_corrected_choice_content_v1.py)
extends the existing signed occurrence arithmetic to the explicit corrected
four-step study. It requires the complete original24-slot analysis and retains
all3 reference rows plus24 compound own-attempt rows, including every generation
or execution null. Nulls have unavailable content, not measured zero utility.
A completed empty accepted set, by contrast, is a measured zero.

For each completed observation it verifies the sealed observer, all original
three-position integer ratings, means, content-identity consistency, occurrence
count and native float U/Q metrics. Repeated records remain repeated. Exact
rational signs and sums explain the original arithmetic but never replace the
floating loss or frozen primary/own-only selections. Negative contributions
remain possible in the reader: the current prefix's absence of negatives is
not hardcoded. A fixed-record deletion arithmetic gain holds scores and every
other consequence fixed; it is not an attainable policy counterfactual, a new
objective, global optimality or evidence about future research/resource effects.

A later data-only extension reports each world's distinct contents and repeated
occurrences, and the sum of per-world distinct counts alongside the global
distinct-content count. Within-world duplication and cross-world sharing are
not the same phenomenon. These diagnostics never deduplicate accepted records,
change a loss or turn matching worlds/content panels into independent samples.
Empty completed worlds have both counts0; failed/generation-null content remains
unavailable. The older45-case receipt below predates this additive extension.
