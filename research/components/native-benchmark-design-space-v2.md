# Benchmark freedoms are explicit experimental domains

Implementation: `utopia/optimization/native_design_space.py`.
Original researcher/world weights and metrics stay outside the design object.
These domains are an ablation, not the grammar or ceiling of every institution.

| Domain | Searchable | Fixed |
| --- | --- | --- |
| parameters | Six declared in-range numeric coordinates | Source and every other literal field |
| code-fixed-graph | Same coordinates plus all three existing Python sources, including wrapped delegate | Schemas, ports, nodes, edges, schedules and remaining fields |
| code-and-graph | Any technically valid SystemSpec code/mechanisms/wiring/process edits | Experimental initial seed; outside world/model/evaluator |

Compare candidates to the original anchor, not the preceding incumbent alone.
Mask only declared numeric leaves/source strings, then compare canonical hashes
of the remaining complete document. Booleans are not numeric coordinates;
nonfinite/out-of-range values and wrong integer types fail. Reordering or
cosmetic field edits also lie outside the fixed-literal domains. This strictness
must be reported rather than described as unlimited fixed-graph semantics.

`NativeAdaptiveDesignCampaign` accepts optional `design_space`; omission retains
the old binding/request. Both feedback policies expose the same domain, and the
bounded active prompt includes it alongside exact read-only request archives.
Compilation checks each actual proposal before any native world. A violation
retains the literal submitted definition and null error; no projection/repair.
It can pass generic graph validation and still fail the declared experiment
domain, so distinguish this from generated-code runtime failure in reporting.

Staged validate/finish also check the actual deterministic singleton draw against
the same original anchor before returning a successful definition. The author
can inspect and revise a scope violation within its existing charged actions;
there are no extra calls or host edits. The immutable anchor is in the exact
request archive, not duplicated in the active prompt. The final controller
independently checks domain membership again. Static validity still does not
establish executable/scientific success, and the calibration is not a guarantee
that an arbitrary generated proposal will run.

The uniform parameter proposer reuses the same ask/tell record and sampled
request seed. It emits literal numeric patches; it is not free program synthesis
and does not differentiate model/source probabilities. Search methods and
freedoms remain separate axes.
