# Independent autonomous model-to-native evidence audit v14

`scripts/analyze_native_autonomous_search_v14.py` reads the frozen aggregate
pilot plan and each immutable runtime plan, original unchanged adaptive/nested
campaign state, automatic designer journal and physical native evidence. It
never calls a model, simulator, generated function or container. The complete
raw inventory is checked before and after analysis; repeated analysis is
deterministic. Output must remain outside the raw tree.

The preregistered three requests are throughput black-box two slots, reviewed
production-efficiency black-box two slots, and production-efficiency nested
four slots. All use the exact supplied initial system, five authors, two native
years, scientific seed42, fixed Qwen and fixed corpus. They are three development
requests, not a controlled comparison of methods. The nested controller retains
its original `[2,1,1]` schedule and one conditional likelihood-ratio step;
black-box uses one new freely authored definition per native slot. A failed
generation consumes its stage's scheduled slots with null losses, including
two initial nested slots; neither replacement samples nor a merit veto apply.

Every executed native runtime Python blob, the actual **v14** pilot driver,
frozen protocol and reused checkpoint/source/routing/plan helpers are compared
to the actual experiment source commit. The audit does not claim equivalence
between different historical/current pilot drivers. Analysis code has a
separately recorded hash.

Designer proofs join exact controller request and provider/settings binding to
the deterministic objective/history/error prompt, durable dispatch intent,
original raw assistant/HTTP response, strict parsed JSON, unmodified authored
operations/factors/coordinates/logits, deterministic patch/provenance envelope,
consumed definition, sampled system, literal parent delta and native checkpoint.
The host cannot silently repair source or invent an identity fallback. Bounded
technical draft failures, interrupted requests and the final malformed
`generation_failure` sentinel remain explicit.

Durable dispatch intent, recorded POST payload, known HTTP/raw assistant reply,
and valid draft are different counts. An attempt with no completion remains
unknown and consumes the attempt; the audit makes no exactly-once HTTP claim.
Model-call/transport seconds and tokens are sums of available recorded values
with record counts, so missing costs are not inferred to be zero. Designer
costs are separate from native scientist wire requests, response journals and
checkpoint model-call time. Provider digest preflight GETs are not model
generation POSTs.

The read-only source-pinned v13 physical primitives remeasure losses from
original PaperTracker checkpoints, verify native identity/annual event
prefixes, source execution/container receipts and original response journals,
and reconstruct complete plans and actual reviewer tasks. All checkpoint
cross-scores reuse development worlds. Physical directories, completed worlds,
charged slots, partial failures and all exact incumbent ties remain distinct.
The v14 analyzer privately binds the exact original trusted helper bodies to a
narrow response-audit extension: an absent wire file is legal only with an
empty response SQLite journal and zero checkpoint response counts. It creates
no empty raw journal and changes neither historical helper modules nor their
normal present-wire validation. This supports legal failures before first
scientist HTTP and legal zero-response worlds without inventing evidence.
Scientist wire requests and recorded code executions are also totaled across
partial directories, separately from completed-world counts. Failed sandbox
calls without a completed code receipt are not falsely counted as recorded
successful executions.
Literal source/topology edits and execution do not prove a useful new algorithm,
scientific value, designer improvement, generalization, variance reduction or
method superiority. Held-out evaluation and promotion policy are undefined.

`scripts/figures/native_autonomous_search_v14.py` requires the exact terminal
audit, content hash, raw/source proofs, bounded claims and actual source pin.
It independently replays compact controller histories and validates native
losses, literal edits, accounting and all ties. The 5.5-inch six-panel figure
shows three separate paths, authored edits, separate designer/scientist costs
and physical-versus-charged slots. Synthetic tests require an explicit flag and
carry a conspicuous fixture watermark; they are not actual outcomes.

```
.venv/bin/python scripts/analyze_native_autonomous_search_v14.py \
  --run /absolute/immutable/native-autonomous-search-v14-a1 \
  --expected-source <actual 40-character source commit> \
  --output research/results/native-autonomous-search-v14-a1.json
```

An incomplete snapshot requires `--allow-incomplete`. No actual evidence is
implied by the scripted contract tests.
