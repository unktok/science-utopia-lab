# Independent staged author/native audit v15

`scripts/analyze_native_staged_search_v15.py` is a new read-only auditor. It does
not change or reinterpret historical v14 audit code. It imports the exact pinned
native evidence routines and strict staged interpreter, then independently joins
their outputs to original provider transport, persisted queue rows, exact plans,
own histories, raw-file inventory and all scheduled costs.

## Verification layers

1. Exact pre-inference plan, two objective identities, native/authoring budgets,
   source commit, fixed original seed, provider/model/corpus/image/hash-seed.
2. Exact source blobs for every native Python module, the actual pilot driver and
   recursively imported physical/audit helper scripts, loss files and protocol.
   The reporting script's own hash is recorded separately. SCRIPTED tests never
   receive an actual-source or actual-model claim.
3. Original staged request binding and terminal journal; `replay_staged_generation`
   reproduces every prompt, raw parsed action, JSON edit/splice, draft, static
   validation, explicit finish/failure and exact consumed campaign definition.
4. Original fixed-Ollama request and HTTP response, exact seed/schema/options,
   raw assistant text and finite recorded costs. Accepted tools cannot be
   attributed to missing, truncated, foreign-model or failed HTTP replies.
5. Read-only campaign reconstruction checks own previous history/loss, generated
   definitions, draw identities, nulls, all exact ties and optional nested update.
6. Existing physical audits restore original native checkpoints, remeasure loss,
   join actual source/Docker effects and scientist wire/response journals, and
   verify initial and yearly lineage. Queued terminal status is not substituted
   for physical native completion.
7. Queue database rows, exact saved projections and observed authoring traces are
   matched to the audited campaigns. Provisional live telemetry stays explicitly
   observed rather than becoming a scientific outcome.
8. Undeclared author journals, native sources, response caches or cross-arm reuse
   fail closed. Before/after inventories prove the audit did not mutate raw
   files. No model, container or native world is constructed by the auditor.

The `--compact` publication form retains exact source/raw hashes, all scheduled
rows, all turn receipt hashes, costs, tool counts, final draft and definition
identities, plus the reproducible full-audit content hash. Large raw prompts,
assistant bytes and transport bodies remain outside Git; a full audit can be
regenerated without inference. Generation lists follow campaign chronology,
not lexical hash-directory order.

For conversational engineering revisions, the exact source-pinned
`build_conversation` and `SYSTEM_PROMPT` reconstruct the actual multi-turn
provider messages. The auditor additionally checks the conversation schema and
source-prompt hash. The protocol path and engineering revision come from the
fully revalidated frozen driver plan, not from an a1-only filename assumption.
The historical a1 interpreter/report checkout remains separate and unchanged.

Per-generation summaries distinguish successful edit/splice turns, authored
operation count, `base_patch: null`, node/wire counts, exact parent/base document
hashes, literal source/protocol/wiring/process deltas and explicit exact parent
retention. An additional graph projection excludes metadata for diagnosis;
metadata can itself affect execution, so equality of that projection is not
called behavioral equivalence. No source inherited from the developer seed is
automatically attributed as new model-invented code.

Own previous observation IDs/statuses/scalar losses and the selected parent
observation are explicit feedback links. Every compact native row retains A
(accepted decisions), Q (actual accepted raw-peer-score sum), R (actual review
records), same-checkpoint cross-scores, native checkpoint identity, scientist
reply/wire and recorded/committed code counts, with hashes of complete activity
and capability proofs. These descriptive fields are not additional optimization
constraints or extra native evaluations.

## Interpretation boundaries

The operational loop flag means two source-joined completed original-world
evaluations in at least one arm, with the exact earlier scalar/failure history
replayed into subsequent authoring. It does not require novelty or improvement,
nor claim model/inventor learning, science-policy benefit, full-world pathwise
autograd, held-out validation, method superiority or same-society adoption.
Parent retention is legal and is not labelled as new code invention.

Dispatch intent, recorded POST attempt, known HTTP/model response and interrupted
unknown are counted separately. Unknown costs are not imputed. Binding/native-
factory metadata GETs are not fully journalled and must not be inferred as zero.
The queue and authoring summaries are consistency evidence, not a cryptographic
provider attestation or proof that scientific content is true.

Use a terminal frozen raw tree. `--allow-incomplete` supports queued/unstarted or
technically aborted campaigns; a nonterminal author journal without a terminal
result is deliberately not completed by a read-only auditor. If the author
interpreter changes for a new revision, preserve a matching historical analysis
checkout for the old run and use a separate new checkout for the new run.

SCRIPTED contracts cover bounded null paths, source/history/prompt corruption,
unknown interrupted responses without redispatch, exact original transport,
finite costs, queue idempotency/projections and unaccounted physical artifacts.
Two complete-original-world positive fixtures also execute four native worlds
each with SCRIPTED scientist replies: one metadata-only design path and one
new literal Python node/schedule path through the actual pinned Docker executor.
They verify original scientist wire/cache/checkpoints, exact evaluated candidate
source/graph, measured loss fed into the next design, distinct physical runs,
and unchanged raw evidence under repeated complete audit. Neither fixture is an
actual-Qwen experiment or a useful-invention result.
