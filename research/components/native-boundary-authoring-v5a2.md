# Boundary-aligned authoring amendment v5a2

The v5a1 failed drafts are not repaired or replaced. Historical
`NativeRegionIRProposer`, `native_region_ir` and native chronological probes
remain unchanged, allowing exact old prompt/receipt-chain reconstruction.

The new `NativeBoundaryRegionProposer` in
`utopia/optimization/native_region_proposer_v5a2.py` has the same callback API,
but a distinct `scienceutopia.native-region-proposal.v5a2` receipt binding.
New campaigns must explicitly select this authoring format and pin its source;
this is not permission to append an unbudgeted fourth draft to an old campaign.

The amendment fixes an incidental representation mismatch: old recorded input
ports `after`/`observations` were displayed beside different authoring aliases
`next`/`world`. Actual incoming edges now determine alias-keyed prompt examples.
The designer sees `boundary:next` and `boundary:world`, channels, artifact types
and separately labelled payload schemas, not operational host endpoint objects.
Payload examples retain explicit lossy-world projection notices. Original raw
contexts, full records and their hashes are untouched and still drive probes.

The first authored node's source grammar enumerates only actual boundary
references. In an ordered zero-delay DAG it cannot legally read any local node,
including itself. Later nodes retain arbitrary references to earlier outputs,
new protocols, free Python and full explicit wiring. This is syntax validation,
not a choice of institutional algorithm or topology. Compiler code and authored
Python are not transformed; missing semantic wires are not filled.

An output-envelope-only example distinguishes transport `{payload:...}` from
the decision payload itself. The native empty-cycle marker is stated explicitly;
raw decision dictionaries and empty required outputs remain technical failures.
No review-score threshold, quota, merit floor, fairness veto or accept/reject
algorithm is supplied. Both reject-all and all-accept remain legal designs.

Generated incumbent/history source stays exact while graph endpoint names are
mechanically projected to scoped aliases. The last at most two generated
candidate regions remain paired with their actual losses. Bounded repair,
saved-before-probe drafts, null technical scores, exact resume and tamper checks
are preserved. Passing these software tests is not an additional Qwen result.
