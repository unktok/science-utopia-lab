# Prospective fixed T/P evaluation path

The [versioned protocol](../protocols/campaigns/native-capacity-fixed-evaluation-v1.md)
and driver prepare a separate finite evaluation of the pilot's original own
selections and all five common controls. No actual evaluation is prepared or
dispatched here. The closed pilot's complete effects, failures and costs will
determine whether that follow-up is useful and its one-to-three unused seed
list, fixed before any of those outcomes. No expand-until-win, reselecting,
baseline fallback, critic call or extra scientific constraint.

The original normal closure, double cold audits/raw inventory and literal
selection are required. Changing P's instrument source bytes fails even if its
metric name is retained. Exact losses, world conditions, scientist/corpus and
all selected source/wiring remain; only runtime source and native seed are
rebound. Null selections stay unavailable. All logical labels survive exact
policy deduplication. Unknown/nonexistent journal roots or consumed seeds stop
before inference. Every actual job, null, checkpoint, cache and role load is
accounted for by the original-source cold audit. No generated code is executed
by an audit. Fixed-policy evaluation is not independent optimizer replication.

Implemented entrypoints:

- scripts/run_native_capacity_fixed_evaluation_v1.py: explicit seed preparation,
  actual native forward/P measurement and fixed-budget dispatch;
- scripts/audit_native_capacity_fixed_evaluation_v1.py: original initial/every
  annual checkpoint P plus base measurements, exact dispatch/source/seed joins;
- scripts/finish_native_capacity_fixed_evaluation_v1.py: normal closure followed
  by two original audits and two separate observed cost projections;
- scripts/reports/native_capacity_fixed_evaluation_v1.py and its finite finish
  wrapper: every logical/physical score, all paired references, failures and
  actual CSV/PNG/SVG, without confusing P with U;
- explicit capacity-fixed-evaluation effect/input scopes: native code, funds,
  founder boundaries and full original researcher requests.
