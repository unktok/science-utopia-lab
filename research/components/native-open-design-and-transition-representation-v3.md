# Open native design and composed transition representations v3

2026-11-01. Two non-scale implementation tracks run concurrently against the
original researcher world. This does not replace that world with a simpler
numeric simulation. See the [protocol and amendments](../protocols/campaigns/native-parallel-invention-backprop-v3.md).

## What changed

1. **Exact native code observations.** `RecordingCodeExecutor` saves the actual
   code artifact, complete input context, result and container receipt locally.
   `parent_context_provider` verifies their hashes against the completed parent's
   persisted node-execution events and native checkpoint, not an ungrounded
   example or an in-memory receipt that disappears after restore.
2. **Arbitrary existing source ports.** `NativeFreeSourceRevisionProposer` can
   revise a Python institution with arbitrary declared ports, rather than only
   the older observations/messages shape. It binds the true objective and prior
   native observations. Only the prompt view is compressed; isolated probes use
   full native inputs. Valid identical, inert and worse programs stay legal.
3. **De-novo source.** The optional parent-source-withheld mode removes all
   parent Python bodies recursively BEFORE lossy prompt projection. Exact final
   prompts, unedited generated Python, technical errors and AST-equality
   diagnostics are retained. AST inequality is not a merit requirement.
4. **Joint new implementations and wiring.** `compile_region` accepts model
   manifests specifying node IDs, Python functions, parameters, port/payload
   schemas, newly named protocol types, internal connections and execution
   phases. `probe_selection_region` runs the generated internal messages and
   JSON memory in containers using exact previously observed boundary inputs.
   The native publication outputs retain real paper/conference identity.
   No developer algorithm catalog is selected by this compiler.
5. **Native-derived compositional autograd.** Real native interventions vary
   annual selection rates independently. Checkpoint-derived year-boundary state
   features and controls fit local annual transition models. Their tensor
   composition yields a terminal loss with actual `backward()`. Control/state
   confounding fails identification; fitted ridge cannot mask deficient rank.
   Whole-schedule convex-hull, state-manifold and radius checks constrain model
   queries. Two unused native control schedules test prediction and directional
   fidelity; one gradient-proposed schedule may receive a fresh native rollout.
6. **Actual startup reproducibility.** `set_seed` no longer pretends that
   changing `PYTHONHASHSEED` inside a running process sets its hash salt. The
   native factory requires an explicit numeric startup setting and records the
   startup environment and an actual hash probe alongside RNG seeds.
7. **Parallel pipelines, bounded inference.** Participating workers share an
   explicit local file lock around actual inference HTTP calls. Separate
   campaigns remain active concurrently while only one request uses the
   resident endpoint at a time. This is not a measured inference speedup.

## Interfaces and reproducibility

Run long jobs only from a **clean pinned experiment worktree**, using the shared
uv-managed main virtual environment. Set `PYTHONHASHSEED=42` at process launch;
an RNG seed argument is not equivalent. Raw outputs, prompts and caches remain
local and ignored by Git.

  scripts/run_native_transition_calibration.py --help

The de-novo CLI freezes only the upstream completed records before model
generation. It records baseline origin as **reused upstream, not rerun**, checks
the execution-only source identity, and saves a candidate with provenance.
`run_native_design_loop.py --proposer fixed --budget 1 --system ...
--initial-provenance ...` then evaluates that exact candidate in a fresh world.
This is not a hidden extension of the upstream campaign's budget.

`complete_native_transition_v3.py` is the separately pinned analysis continuation
for the original8a114f3 calibration. It waits for the six already-budgeted native
cells, verifies their exact legacy extractions, excludes only the PaperTracker
archive destination from scientific-state identity, and stores both hashes
without rewriting any original bundle. It then fits/validates the representation
and, if supported, runs at most the one already-planned fresh gradient proposal.
Execution-only source, model/corpus and scientific/RNG initial identity must
match. It automatically writes independent derivative/native audits or a
structured failure. Original calibration is not rerun and failed derivative
fidelity is not silently fixed by replacing validation points.

Read-only independent audits are provided by
`audit_native_open_source_v3.py`, `audit_native_de_novo_v3.py`, and
`audit_native_transition_v3.py`. They rederive native losses and source/model/
corpus/checkpoint bindings. The latter separately checks autograd using central
differences **inside the same fitted representation** and checks fidelity using
unused actual native simulations. Those are different tests.

## Exact current limits

- Existing-node revision still holds its ports and wiring fixed. Joint regions
  are a different route, not extra freedom implicitly attributed to that class.
- The first joint region replaces a selection boundary only, with 1–6 Python
  nodes, at most32 edges, annual zero-delay acyclic internal routing and native
  publication exits. General patches can edit a broader graph; this particular
  safe probing adapter does not yet cover arbitrary native boundaries, delayed
  loops, cross-year messages or replacing the whole society at runtime.
- Passing developer-scripted region tests demonstrates implementation only.
  It is not evidence that local Qwen invented a working or beneficial region.
- All generated source executes only in the existing no-network, constrained
  Docker runtime. The host does not execute model Python.
- The transition representation uses six measured features. They are not a
  sufficient full Markov state for text, histories, retrieval or arbitrary new
  institutions. SVD does not remove that modeling limitation.
- Derivatives are exact for the fitted model and **approximate for the native
  world**. They are not token-level derivatives, native Python derivatives,
  unbiased native expectation gradients or completed full-world pathwise
  backpropagation. Fixed LLM weights do not make LLM responses constant.
- A represented gradient can disagree with discrete hard outcomes. Validation
  points are not rerolled after seeing that disagreement. Fresh proposal benefit
  and derivative fidelity are separate results.
- The negative accepted-decision count is an intentionally gameable engineering
  objective. Even an all-accept optimum does not establish scientific quality,
  useful institutional invention or a policy recommendation.
- Same-society hot migration and recursive improvement of the designer remain
  separate unimplemented goals. A fresh-world proposal loop is not those things.
