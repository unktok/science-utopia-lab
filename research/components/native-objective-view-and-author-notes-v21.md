# Objective arithmetic and untrusted author annotations

The native author can inspect the exact optimization arithmetic without being
given a candidate policy. The objective view derives each affine metric term's
coefficient and per-run preferred direction from the selected LossSpec, keeps
the seed aggregation unchanged and recomputes its own recorded loss components
through the existing loss evaluator. For the archived measurements, `-A` gives
`-1`, and `-Q+0.5R` gives`-4+12=8`.

This arithmetic does not predict how an institution changes a metric or provide
a world gradient. It holds other inputs fixed; coupled effects and seed
dispersion can change the aggregate. The author must invent the actual source,
parameters, institutions, wiring or processes and use native measurement. A
trusted instruction distinguishes this task from verifying correct parent code.

## Source and observation fidelity

The pure view reads only the current request, draft and own observations.
It preserves recorded failure status and null losses. Missing measurement
objects and missing/foreign loss bindings produce explicit unavailable states,
not zero penalties or cross-objective measurements. A literal draft difference
is labeled as such, not called behavioral novelty or improvement. A declared
sampling distribution is reported separately from the concrete draft.

The view is session data; observed strings are not promoted into SYSTEM
authority. No new world, source execution, candidate policy, optimizer update,
quality/fairness/promotion rule or hidden eligibility test is introduced.

## Prospective tool annotation contract

Every tool may carry optional rationale and provenance as typed, untrusted
author notes. Rationale is a nonempty string of at most4096 characters;
provenance is an object with at most16 top-level keys. Exact raw actions and
receipts preserve these notes. They do not alter candidate state or become
trusted compiler/operator provenance. Other undeclared fields remain invalid.

Configure must still contain at least one actual factors/continuous/logits
field; notes alone do not configure a distribution. Finish still requires
authored rationale and the full existing validity checks. Literal edits remain
literal, all graph/code/process freedom and explicit retention remain legal,
and no invalid source or missing action field is repaired by an annotation.

This is a new declared contract. Historical extra-field rejections remain
rejections at their actual frozen sources. Accepting notes alone would not
recover a changed institution from the eight identical V19 edit operands.
