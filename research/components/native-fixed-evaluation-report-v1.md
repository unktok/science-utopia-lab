# Reporting the separate fixed policy evaluation

The report joins the stopped original search to the separately frozen evaluation
without completing the old experiment or replacing its missing policies. It
requires two byte-identical closed original-source evaluation audits, the exact
evaluation plan, and the unchanged stopped-prefix audit and original plan.
The live study is not read for interim scores.

The portable report retains all twelve original proposal slots, including six
technical nulls and the unsubmitted final numerical slot, and all original ties.
Every new physical world is joined to its frozen policy, seed and labels. Both
optimized losses and the descriptive selective score are recomputed from the
literal measurement. The six reference labels and all six selected-arm labels
receive explicit seed rows. The two arms without a completed submission have
unavailable scores and no physical job, not zero loss or an initial-policy
fallback. Shared labels remain linked to the same physical world.

The output contains per-seed common-score plots, original search paths, physical
A/Q/R components and paired differences against every reference. Three seeds
describe these selected policies; they are not independent optimizer histories
or an equal-search-budget comparison. Source changes and selection after a
stopped prefix remain explicit. The figures do not establish scientific truth
or a benefit from greater structural freedom.

`scripts.finish_native_fixed_evaluation_report_v1` can wait at a separate clean
analysis source for the existing audit/cost chain to close. It checks the two
audit and cost copies, builds the report twice and compares every output byte.
It never starts inference, retries a failed build, changes selection, fabricates
an absent terminal or marks the publication goal complete. Actual visual review,
interpretation and manuscript integration follow the build.

Synthetic QA exercises missing policies, shared worlds, measurement and binding
tampering, chronological failures, deterministic PNG/SVG/CSV rebuilding and finite
continuation failure paths. The first rendering test exposed random SVG IDs in
the reused renderer; an explicit plotting hash salt fixes byte reproducibility.
The original failed receipt is retained. Layout previews use synthetic values,
not current experiment results. The actual report has not yet been generated.
