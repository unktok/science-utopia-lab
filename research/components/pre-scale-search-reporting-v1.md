# Closed search report and numerical rebuilding

The finite T/E study keeps all six fresh reference forwards, all16 candidate
slots, fixed selections and three-seed evaluations. Reporting uses its completed
original-source audit, not live progress files. The implemented rebuilding
path has synthetic software verification; execution on the actual closed O/E
data remains pending while science continues.

## Retained observations and policies

The report retains every assigned status and available T/E/C score, exact
selection ties and dispatch order, raw checkpoint measurements with their
metric statuses, and the exact executable systems indexed by content hash.
Development rows are joined to the original audit's ordered physical worlds;
repeated specifications are not matched by guess. An unsubmitted proposal has
no physical job, and every actual development forward has its own identity.

All source-owned authoring records are preserved when available, including
generation errors and literal definitions. Their prose is untrusted evidence,
not a mechanism implementation or proof of why a failure happened. Physical
execution can finish even when an assigned loss is unavailable. Conversely,
a checkpoint measurement does not retroactively change an unscored/null
training observation into a successful proposal.

Selected labels explicitly share identical physical evaluation jobs. The
report retains both logical rows and the distinct job count. T/E are the
optimized objectives; C is a common diagnostic score. No extra C search is
inferred from a C column, and repeated labels do not create independent worlds.

## Commands after actual study closure

Use the existing approved project interpreter from the repository root,
not Apple Python. First project an actual completed original-source audit:

```text
.venv/bin/python -m scripts.reports.pre_scale_search_v1 --audit <closed-original-source-audit.json> --output <fresh-report-directory>
```

The output contains the complete report, its manifest, objective-conditioned
best-including-initial paths and a selection-fixed common-score figure, each
as PNG/SVG. The common view shows the three unused seeds, missing values and
available counts, while stating physical versus logical observation counts.
Its plotting functions execute no authored institution code or model.

Retain those exact report/manifest/figure bytes. Independently rebuild their
numerical summaries and graphics with:

```text
.venv/bin/python -m scripts.reports.pre_scale_search_reproduce_v1 --report <retained-report.json> --manifest <retained-manifest.json> --figures <retained-figure-directory> --output <fresh-independent-directory>
```

Rebuilding checks all16 slots, declared chronology, all available cross-scores
from measured A/Q/R, best-so-far paths, per-arm and pooled exact ties, selected
executable policies, seed-only evaluation projection, shared physical counts,
descriptive summaries and every paired-reference difference. It regenerates
identical report/four figure files and a physical-world component CSV. The CSV
preserves unavailable/not-recorded fields as empty values with explicit
statuses, never as zero. Inputs are not overwritten; the destination must be
fresh and outside input directories.

This is retained-data reconstruction, not another full raw audit or fresh-model
replication. Full source/checkpoint/request proof remains in the original
audit. Provider costs use the separate closed-audit cost projection; summed
scientist-call intervals are only a component, not total experiment duration.
