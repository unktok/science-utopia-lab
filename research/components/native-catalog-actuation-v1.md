## What the capability changes

`native.catalog-project.v1` selects an actual catalog topic in an active idle
researcher's displayed expertise. It validates the entire original direction
record, current start year and original end year, then uses the existing
atomic native project handler. It cannot shorten ongoing projects, mint
outputs, change activity flags or create funds. The validator accepts any
displayed catalog topic; shortest duration is a separate developer policy,
not a hidden rule imposed on authored institutions.

The named `fixed-native-production-catalog-planning-v3` domain grants this
action while retaining protected native production and forbidding unrestricted
`native.project`. Old fixed-production and review-routing domains continue to
reject the new grant. The broader existing open-domain action is unchanged.

scientific invention or a claim that the preceding pilot already had it.
