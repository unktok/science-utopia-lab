# Literal fixed-consumer evidence for institutional authors

An optional `strategy_provenance.native_consumer_source_evidence` package now
reaches the bounded author's active USER data before planning and on later
turns. With the option absent the original active frame remains unchanged.
The new profile source hash is included in the ABI/runtime binding. Legacy
frozen runs/certificates are not relabelled as using this option.

`utopia.optimization.native_consumer_evidence_v1.build(source_commit=...)`
constructs six literal code cards from the selected fixed consumers and
measurement code. Each binds exact file bytes, AST-selected declaration or
complete module, original line range, excerpt hash, extractor hash and full
committed source identity. It verifies actual Git bytes, including its own
extractor, not just a self-hashed JSON object. In-request validation reconstructs
the selected current bytes and requires the request world's source identity.
There is no dynamic import or execution of the displayed code or authored code.

Selected interfaces: resource clipping/deactivation; canonical project validator;
original core-plus-one-hop topic action; native resource-transfer consumer;
native publication-decision consumer; complete passive collected-cost module.
The selection is not the entire world API. An extracted function's imports and
helpers outside its range are explicitly not implied to be included. Neighboring
hand-control code is not copied into the package. No terminal-consolidation
implementation or suggested new institution is included.

The package has a40,000-byte inline ceiling. The actual initial package is
approximately32k serialized bytes, not32k tokens. Both active-source and actual
wire byte guards remain; nothing is silently sliced, summarized or omitted to
fit. Backend prompt/output counts and length termination still need actual
real35B evidence before dispatching the new scientific study.

Authority, initial world, losses, budget, explicit finish and permitted arbitrary
source/node/wiring/process design are unchanged. Failure to understand a card,
produce a new graph or improve loss is not a technical-validity veto. No-op and
unpaid/attrition outcomes remain legal and visible. This is an information
intervention, not automatic repair, policy synthesis, proof of relevance of an
edit or a new scientific observation.

[Prospective matched study](../protocols/campaigns/native-consumer-source-comparison-v1.md)
separates a recovery-of-known-opportunity pilot from an important publication
claim. Driver/public-native proof, real calibration, actual new search and its
independent/unused evidence are not completed by this interface implementation.

## Primary-source scope check, November16

Re-read [AMD-LLM, sections3.1.1--3.1.4](https://arxiv.org/html/2502.12203v1):
it already supplies fixed code boilerplate, evolves mechanism heuristics and
evaluates them, with a problem-specific fixing process. Showing a designer
fixed source or iterating generated code is not our standalone novelty. Our
literal no-host-repair protocol differs, but that difference needs a useful
empirical answer rather than a priority claim.

Re-read [Inefficiencies of Meta Agents, sections3--4](https://arxiv.org/html/2510.06711v1):
it already compares archive/context curation and studies behavioral redundancy
and design expense. The proposed source package is a concrete information
condition, not a newly discovered general principle that context or diversity
matters. Inference from a finite matched intervention should not become a claim
that missing knowledge uniquely caused the historical failures.

Re-read [SciMARS, sections3.1--3.2 and4.2](https://arxiv.org/html/2611.12552v1):
it already adapts scientific-task role/coordination harnesses, keeps the outer
optimizer/evaluator fixed and uses matched controls/repeated runs. Our candidate
distinction is optimizing the organizing institutions of a persistent researcher
society under declared losses. Merely exposing evidence or changing code does
not establish that distinction as an important contribution. Appropriate
independent evidence and a substantive objective-to-system finding remain open.
