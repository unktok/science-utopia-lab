# Static instructions as a strong native-world comparator

Status: implemented and verified with original Simulation, real isolated
container execution and scripted HTTP/corpus. **No actual-Qwen instruction
assay or new policy optimization has run.** This is not added to the active
61a1753 experiment, its five references, or its fixed evaluation.

## Purpose and interface

A freely authored institution should be compared with simple alternatives that
have the same actual authority. A static instruction is one such alternative:
it may steer an original researcher's choices without replacing the researcher,
directly overwriting a project, or changing production/calendar laws. Its
effectiveness remains an empirical question, not a property of this builder.

`instruction_control(anchor, image_id, instruction=..., delivery_phase=...,
connected=True, first_period=1)` in
`utopia/system/native_information_institution.py` adds one ordinary code
producer and a native context receiver to the caller's complete original-world
anchor. The literal nonblank instruction is at most8192 UTF-8 bytes; it is
neither translated nor interpreted by the host. The caller explicitly chooses
its one emission period and delivery phase. There is no menu of policy aims.

The producer runs just after `world.open` and addresses actual author-capable
actors from that observation, without a new active-status or scientific-merit
gate. It emits the instruction only in the declared period, then empty outputs
on later invocations. Native persistent context retains delivered messages.
No project, resource, publication or review effect capability is granted.

Early and late variants keep the exact same producer, parameters, code, world
input edge and source schedule; only the receiver's phase differs. The cut
control removes only its delivery edge. It still runs the same producer.
Native `world.close` is not the graph/year checkpoint: existing dossier
institutions already execute after it, so the helper does not invent a new
pre-close restriction. Ambiguous schedules and identity collisions reject.

## Actual software evidence

At clean source63ae983519a5331469af1ce78f6b1309601b925d, the combined instruction,
existing information-institution and fixed-production-domain suite passes
40 checks in124.05s. The [verification receipt](../results/native-static-instruction-controls-verification-v1.json)
retains exact source/file/JUnit hashes and prior failed QA, not just the pass.

The actual original-world/container cases verify:

- All full model request payloads in two-year cut and unmodified-anchor runs
  are equal, despite varying host clocks and raw graph/audit identities.
- The first affected direction input is year1 for phase2 delivery and year2
  for phase235 delivery in the one-year-project fixture. A declared period2
  emission first appears in year2. This is not a prediction for longer projects
  or actual Qwen choices: the next eligible native decision can occur later.
- Four original authors each receive exactly one literal message, with the
  correct emitted/received period and preserved Unicode. Early/late/cut
  producer result hashes agree in both years; no plan amendments occur.
- A period3 late message survives an actual year3 interruption and cold
  restart. Six-year scientific state and the full canonical kernel match the
  uninterrupted run, with four—not eight—delivery events.

These are replay/connection tests, not independent scientific observations.
Equal producer compute is not equal total model token cost: receiving context
adds tokens and may alter later requests, work and outcomes. A future assay
must retain those actual costs. Early/late worlds also need not differ only
through a single later mediator; their full subsequent histories can diverge.

## Next scientific use and limits

No instruction text, finite scientific assay, additional objective, selection
rule or evaluation seed is frozen here. The current objective study must close
under its existing plan. If an additional information-opportunity assay is
needed, declare its literal messages, recipient rule, phases, conditions,
native-world budget and observer/measurement contracts before inference.
Do not add it as a post-hoc control inside the running fixed evaluation.

The control is developer-authored, not an autonomous discovery. Its existence
does not establish that information changes production, improves any loss,
separates T/U optima or closes publication milestoneR2. It supplies a concrete
same-authority alternative for a later research comparison, not a new optimizer
or a scientific-truth verifier.
