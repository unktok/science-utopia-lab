# Native parameter-only comparator

This is an explicit small-budget comparator for free-program optimization,
not a replacement of the wider scientific-system design goal. Its
[protocol](../protocols/campaigns/native-parameter-comparator-v1.md) reuses the
closed planning pilot's literal common bank, selects the same initial parent
by assigned T/U loss, and changes only an already consumed reserve parameter.
New mechanisms, sources, wires and schedules remain available to the free
method, but not to this numeric comparator. No hidden merit gate is added.

## Implemented path

- [Complete-SystemSpec parameter space](../../utopia/optimization/native_parameter_space_v1.py):
  strict existing coordinate mapping and literal nonnumeric preservation;
  existing adaptive random search with one explicit measured-anchor warm start.
- [Finite runner](../../scripts/run_native_parameter_comparator_v1.py):
  exact audited original bank,265 unchanged original native/source files,
  bounds1--60, two three-proposal histories, pre-dispatch/post-feedback states,
  six original scientist worlds and own-only selection.
- [Cold auditor](../../scripts/audit_native_parameter_comparator_v1.py):
  deterministic asks/tells, exact states/selection, original scientist role
  loads, native checkpoint/consumer/request proof and original critic replies.
- [Full-slot reader and figure](../../scripts/reports/native_parameter_comparator_v1.py):
  all8 reused references, all6 prior free slots including generation nulls,
  all6 numeric slots, both loss cross-scores and two path panels. Existing
  [cost projection](../../scripts/reports/pre_scale_costs_v1.py) includes every
  new scientist/critic/load call separately from the reused common bank.
- [Finite continuation](../../scripts/chain_native_parameter_comparator_v1.py):
  waits for the exact ongoing parent-presentation writer and analysis process,
  requires normal matching double audits/costs and unchanged raw, then starts
  the prepared numeric study once. It never changes the live study, overlaps
  our inference, retries a consumed stage, or restarts on a polling timeout.

The extra wait is resource coordination, not selection on the parent-
presentation results: neither those new scores nor its12 own candidates
become numeric feedback or change the prospective bounds/budget.
