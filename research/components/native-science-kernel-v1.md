# Native science kernel: containment, not a smaller replacement world

## Direction fixed with the user

The original research world is a **lower bound and one instance**, not the
desired ceiling. Abstract its execution without replacing researchers,
language, projects, papers, review, retrieval, funding or longitudinal memory
with numeric attributes. Smaller runs mean fewer actors/years, not less
expressive activity. Numeric program worlds remain method/unit tests only.

The target is a conservative extension: the default graph reproduces the
existing world, while alternative implementations, extra actor/artifact kinds,
new institutions and changed processes can inhabit the same execution engine.
No fairness/promotion veto is introduced. Choice of scientific loss remains
separate from technical execution validity.

## Implementation boundary

`NativeScienceKernel` binds the generic SystemSpec graph runner to a live
`Simulation`. Baseline nodes delegate to the existing phase methods; they do
not approximate or reimplement researcher decision rules. A private ephemeral
frame retains live ResearchDirection/domain objects within a year; graph
messages expose versioned JSON observations and full artifact content instead
of serializing model clients. Default control edges reproduce the old order.
Edges, latency, optional nodes and registered implementations are real design
objects. The baseline graph is a constructor, not the only accepted graph.

Separate native decision selection from publication commit so a replacement
institution can supply decisions while retaining actual conference, tracker,
RAG and downstream funding effects. The compatibility boundary requires real
paper identities and complete decisions, not a preferred acceptance rate.

Generic researcher-context delivery takes arbitrary typed graph payloads and
their causal provenance to real agents. Native prompts include those records;
zero records leaves original prompts byte-identical. Messages and queues are
checkpointed, so a new producer/consumer protocol can affect a later research
decision rather than merely decorate a replay.

Standard-library Python source remains isolated in Docker. It receives live
world records through declared ports and can connect to native consumers.
Trusted registry extensions can implement other capabilities; new mechanism
families are not limited to evaluation/funding. New actors require an explicit
serializer/behavior contract, not silent omission from a legacy roster.

## Verification gates

1. Default-off paths and portable contract shape remain unchanged.
2. Default graph and original coordinator produce identical scientific state,
   RNG state and model request payloads under the same recorded/scripted replies.
3. No phase or researcher behavior is mocked in the native lifecycle tests;
   only model/corpus transport can be explicitly scripted for deterministic QA.
4. A producer -> novel payload -> recipient chain changes real prompt input;
   removing the edge or delaying it changes when that input is available.
5. A replacement decision mechanism changes native publication state and
   subsequent researcher context without replacing the researcher world.
6. Checkpoint/resume preserves graph state, source identities, pending messages,
   actor context and canonical events; mismatched specs fail rather than vanish.
7. A clean, pinned local-Qwen run is separate evidence from scripted QA. An
   instruction arriving in a prompt is not by itself proof of behavioral effect.

## Differentiation: tied to this world, not a toy substitute

Native LLM calls, corpus selection, hard decisions and resource deactivation are
opaque/discrete nodes. Track those boundaries explicitly; do not claim autograd
through them. Tensor-backed local institutions may expose exact derivatives;
whole-path gradient claims must account for every node on the loss path.
Future surrogate/score-function/relaxation estimators must bind their training
and outer validation to native trajectories and the same scientific objective.
Changing to hand-picked numeric world laws is not native-world differentiation.

The next implementation should separate three derivative contracts:

1. **Exact local derivative:** a tensor-backed institution exposes its state,
   continuous inputs/outputs and parameters without a JSON detach inside the
   differentiated subgraph. Persistence can detach at completed-step boundaries.
   The current JSON graph runner does not yet provide this tensor path.
2. **Estimated native-rollout derivative:** an opaque native transition needs
   an explicit estimator and evidence of its error. A learned transition must
   train on native trajectories/artifacts and be checked against fresh native
   executions, rather than define a convenient substitute science world.
   Differentiating that learned path is not exact native-world autograd.
3. **Discrete/structural proposal:** creating Python source or adding a role is
   still a discrete design operation. Black-box proposal/search remains valid;
   continuous gates over a finite bank do not make unlimited program synthesis
   differentiable. Hybrid candidates must return to the same native evaluator.

Any future whole-system gradient report must enumerate every transition from
design to LossSpec, identify exact/estimated/opaque links, compare gradient
predictions against native perturbations, and record projected executions.
Until that gate passes, report local derivatives or surrogate proposals only.

## Usable entry points

- Existing CLI, unchanged when omitted: `--science-system-spec legacy` runs
  the original-world instance through the graph; a JSON path loads another
  SystemSpec. Normal original model/population/corpus options still apply.
- `legacy_world_system()` provides an editable baseline graph;
  `connect_native_institution()` wires any registered/code/LLM node into it.
  Graph edges/latency/phases are data. Node implementation lookup is trusted
  registry registration, not importing model-supplied host code.
- `native.world.llm-institution.v1` accepts `instruction`, `output_schemas`,
  optional `state_schema`/`response_format`; it uses the actual native model
  with input envelopes, artifact identities, lineage and own persistent state.
  Its output follows the same `outputs`/`state` contract as isolated Python.
- `native.world.researcher-context.v1` routes arbitrary records to explicit
  existing author-capable IDs, not a fixed recommendation taxonomy. Current
  university/industry direction and intention prompts use these records;
  other hard-coded prompts do not automatically become extensible.
- `ActorCodecRegistry` makes trusted new actor classes persistable. Their
  behavior/capabilities still need explicit adapters; serialization alone does
  not make an arbitrary citizen/laboratory role act as a researcher.
- `native.world.artifact-store.v1` records arbitrary protocol payloads. With
  explicit `declare_artifacts: true`, each input declares/updates one new typed
  non-paper identity. Canonical `artifact.created`/`artifact.updated` events
  and replay retain its content and history. Paper/other-store identity
  collisions fail; recording does not make an artifact scientifically useful.
- `evaluate_native_suggestion()` consumes the standard Suggestion, caller's
  Simulation factory/seeds and LossSpec and returns an Observation. It chooses
  no scientific objective or implicit social constraint. Its initial native
  measurement vocabulary is deliberately small and must be extended explicitly.

The original lifecycle wrappers share a live, private annual frame for domain
objects. Consequently removing review/selection is tested, but replacing the
entire research/submission/funding protocol with isolated code is not yet a
fully port-based operation. New source cannot mutate arbitrary host objects.
Further capabilities must expose domain effects through explicit contracts or
trusted adapters; this boundary must not be mistaken for unlimited freedom.

## Remaining scope

This first integration does not implement unlimited event scheduling, every
new actor behavior, empirical realism, or whole-world differentiation. Existing
research selection/corpus assumptions are preserved, not endorsed as sufficient.
The engine must support extensions beyond them; tests establish containment,
not that the original scientific ontology is final.

In particular, the original simulator chooses existing corpus papers to stand
for research output. Retaining that behavior proves containment; it does not
make it an adequate final research model. A richer instance may introduce
hypotheses, datasets, software, protocols, tests, replications, correction and
newly authored artifacts, with producer/consumer behavior and actual longitudinal
consequences. The new generic artifact store only supplies identities/content/
history; it does not implement those scientific activities by naming them.
Prioritize one such multi-step native extension over adding more settings to a
fixed review/funding catalog. Scientific utility needs its own declared loss
and independent diagnostics, not a built-in favorable numeric world law.

Keep representational freedom separate from an experiment's search variables:
write a trajectory as `F_world_model(SystemSpec, environment, seed)`. The world
model can be extended or compared, but an institutional-optimization campaign
must declare which assumptions are held fixed. Changing the world laws to make
a proposed institution score better is not evidence that it improved under the
original objective and environment.

Current observation `extension_state` is the prior completed graph checkpoint,
not other nodes' uncommitted current-year memory. A node receives its own actual
latest state; current-year sharing should use explicit edges. Context history
is append-only in this slice, so a longer campaign needs a versioned memory/
retrieval policy rather than silently truncating researcher inputs.

## Local transport note

Explicit thinking overrides now map to Ollama `/v1` `reasoning_effort`
(`none` for false, `medium` for true); an absent override retains the historical
body. This fixes a prospective execution setting, not old campaign evidence.
The local Qwen endpoint returned the requested JSON with six output tokens
under `reasoning_effort: none`. Primary provider implementation:
[Ollama reasoning mapping](https://github.com/ollama/ollama/blob/main/openai/openai.go).
