## What remains and the next decision

The remaining immediate gap is an autonomous designer that reliably turns the
specified loss and history into a valid executable system, not more seeds or
more simulated researchers. The current local author repeatedly confuses
schema definitions, runtime variables and search-distribution configuration;
precise diagnostics alone have not solved this. This is observed behavior,
not a general impossibility claim about 8B models.

Keep the native researchers at Qwen3-8B. A recommended separate condition is
to use the current Codex as external institutional designer through the
existing hash-bound ManifestInbox interface, recording exact requests, authored
manifests, own-loss inputs and native outcomes. It would not be a local-Qwen
authoring success or a provider-authenticated capacity comparison. It needs a
new prospective finite protocol; no new paid API contract is proposed.
An alternative is to retain an 8B-only designer and revise its planning/task
decomposition before another bounded pilot. The user has been asked which
direction to take; no alternate-provider track or additional pilot is launched
by this report. Do not silently repeat the same fixed-budget failure loop.
