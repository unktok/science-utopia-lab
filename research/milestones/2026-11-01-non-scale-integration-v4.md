# Non-scale integration v4: implementation, evidence and frontier

User direction: pursue all remaining expressivity/integration work before
increasing seeds, population, horizon or search budget. This milestone closes
several executable paths; it does NOT declare the whole research program done.
The original researcher world is the minimum contained instance, not a toy to
replace for convenient optimization. Explicit objective, design freedom and
optimization method remain independent axes. No implicit fairness/merit veto.

## What changed in this iteration

1. Recovered the final v3 audit without new worlds, hiding failure or changing
   data. Both surrogate fidelity and proposal benefit retain their true limits.
2. Added categorical/Bernoulli REINFORCE over complete systems with exact
   log-probability backward, native-cost bindings and durable sampled batches.
   Its analytic/native-scripted QA is separate from the exact offline four-bank
   experiment. The latter fits probabilities only; full native responses are
   already included in its frozen costs, not differentiated token by token.
3. Corrected fixed-wiring probes that used parent memory/sampled years. Candidate
   memory now evolves across ALL recorded native years; prompt examples remain
   explicitly lossy and do not substitute for chronological probe inputs.
4. Built same-society migration instead of equating fresh-world search with
   continual redesign. Cold bootstrap only accepts validated lineage from the
   configured original design; all other scientific contract fields stay exact.
5. Added visual node/port/wire/order authoring and a minimal edit/run/evidence/
   target-feedback game loop without inventing scores or starting inference on
   page views. Missions choose explicit loss/target/budget, not hidden rewards.
6. Ran two separately preregistered joint-generation attempts with local Qwen.
   Both failed before native execution. Generated code was not repaired by
   developers, missing edges were not silently filled in, failed candidates
   were not scored and the exhausted budgets were not secretly extended.

## Remaining non-scale work, in priority order

- **Joint invention authoring and consumers:** separate algorithm/protocol intent
  from incidental local-vs-external identifier syntax, make typed boundary
  references clear, and validate genuine missing wiring rather than supplying
  an unreported host algorithm. Preserve freedom to create entirely new
  institutions, not just select from a predefined rule catalog. Extend native
  adapters beyond currently recorded Python cuts when new consumers are needed.
- **Faithful world-response representations:** rich history/text/retrieval and
  discrete endogenous events are not captured by six aggregate features. Keep
  fidelity diagnostics and actual fresh forward validation distinct from
  numerical gradients inside a chosen representation. Distribution gradients
  are another valid method, not a completed full-world pathwise derivative.
- **Continual optimization:** connect explicit loss-conditioned counterfactual
  evaluation to adoption in the continuing society, without pretending separate
  worlds are one history or that a valid patch is beneficial. Designer code,
  proposal process and the objectives governing it need explicit provenance
  before claiming recursive improvement.
- **Game and semantic breadth:** connect the durable migration API to explicit
  player controls, then richer consequential research-system interactions. Art
  and motion stay presentation-only unless actual domain state supports them.

These are non-scale gaps. More seeds or larger models do not by themselves
implement them. The completed v1.1 held-out study remains sealed and unchanged.
No new native or designer inference process remains active after the recorded
v4 attempts; continuing work must start a new explicit implementation/protocol,
not rely on an idle agent or a nonexistent background job.
