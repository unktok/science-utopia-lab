## The original goal, still the organizing principle

Choose an explicit loss, then search for the **scientific system** that realizes
that objective. Change the loss to investigate how the resulting institutions,
connections, workflows and optimization paths change. Parameters, algorithms,
mechanisms, protocols, wiring and processes are increasing design freedoms,
not unrelated projects and not a fixed catalogue of peer-review settings.

Optimization loss, technical validity, evaluation metrics and optional adoption
are separate. There is no implicit quality, fairness, novelty or benefit veto.
Explicit parent retention, ties and worse outcomes are legal observations.
Failures are null, not invented numerical penalties. Accepted-paper counts and
review scores are disclosed gameable proxies, not scientific welfare.

The original researcher world is a **minimum contained instance**, not the
expression ceiling. Extending it must not be replaced by a smaller numeric toy
solely to make gradients convenient. Researchers' model weights/personas stay
fixed; their responses may change under new institutions and information.
Black-box feedback, likelihood-ratio estimates and useful represented gradients
are methods for that goal. Whole-world differentiability is not required:
[Decision 0028](../decisions/0028-estimators-serve-open-institutional-optimization.md).

## This finite V15 effort

The user explicitly authorizes parallel implementation and continued engineering
until an automatic institution/native-feedback loop works. That does **not**
permit silently extending an already frozen revision, deleting failures, changing
the loss after seeing outcomes, substituting a baseline or supplying candidate
code by hand while claiming local-model authorship.

Parallel work separates three components:

1. Root/runtime: staged local author, unchanged native optimization kernels,
   exact explicit objectives and finite queues, source-pinned actual execution.
2. Native-world extension and independent evidence: open original-researcher
   work capability; exact raw tools/draft/source/graph/native/cost/loss joins;
   cold restart and read-only repeated verification.
3. Existing English Foundry: observed tool chronicle, consent and progress,
   source/artifact/workflow inspection and honest actual-result visualization.

### Actual a1: closed failure, not a native experiment

[Source-pinned a1](../results/native-staged-search-v15-a1.md) exhausts four
generations/four scheduled slots with 64 known designer replies: all actions
are repeated inspections, no explicit finish, no compiled system, no native
world and no scientist reply. Native losses are all null. The 64 replies cost
411.43 adapter seconds and 523,598 input / 2,112 output tokens. Two independent
audits agree, preserve 153 raw files and match 242 critical source blobs.

### Actual a2: original-world own-feedback loop, unchanged candidates

The [a2 protocol](../protocols/campaigns/native-staged-search-v15-a2.md) fixes
four **new** scheduled native slots and at most 64 **new** designer POSTs. It
changes conversation presentation and technical progress cues, not objectives,
researcher weights, population, years, seed, corpus, valid design space or
retention policy. Its raw data and source remain separate from a1. The writer
stops normally with exit0. Two matching-source read-only audits independently
verify [the complete result](../results/native-staged-search-v15-a2.md):
four original-world executions, 368 scientist replies, 32 code executions and
zero technical failures. Throughput losses are [-1,-1]; reviewed-production
losses are [8,8]. Both G1 requests receive their exact own G0 loss/observation.
Every generation performs 15 inspections and explicitly finishes the exact
19-node/27-wire parent, with zero authored operations/source/graph changes.
Thus the automatic native-feedback loop works, not autonomous novel invention.
The 64 designer replies cost 989.67 adapter seconds and 561,586 input / 1,781
output tokens. Two audits agree, preserving 209 raw files and matching 242
critical source blobs; the total actual run lasts about 39 min 19 s.

The operational acceptance condition is two completed automatic native
generations in at least one objective arm, with the first observed loss/failure
history reaching the second authoring request. It is **not** mandatory novelty,
loss improvement, an improved inventor, a policy recommendation or whole-world
differentiability. That condition is now achieved in both arms. It does not
finish every non-scale research direction listed above.

Later production source adds read-only capability discovery at commit
`7c4089e657bd757a5858a27ecf5eff3cd32c93e4`: an actual-registry-derived index
and five detailed generic effect ABI cards, including arbitrary researcher
work, literal Python, bounded processes, domain commands and conserving
resource transfers. Discovery neither supplies policies nor mutates a graph
nor grants privileges. SCRIPTED tests verify no model/native handler/container
dispatch. That future authoring affordance is intentionally absent from the
historical matching-a2 analysis tree and was not used in the frozen pilot.

## Next bounded research, not automatic scale-up

- Examine consequential autonomous design changes under different explicit
  objectives. Report exact source/graph/behavior changes and retention equally;
  do not introduce a novelty gate to force an interesting result.
- Use the newly inspectable generic effect ABIs, not a menu of policies, to
  test an arbitrary new scientific-work/artifact interaction in the actual
  original fixed-Qwen world under a separately declared small budget. Full
  detailed-card coverage and plugin discovery remain incomplete.
- Improve authoring reliability or optionally evaluate a stronger designer while
  keeping scientists fixed. A stronger designer is an explicitly new provider
  choice, not a hidden fallback for failed local-Qwen turns.
- Continue the English game-like interaction and original-work effect views in
  parallel; keep editable drafts, granted compute consent, executed effects and
  optional adoption visibly distinct.
- Use the existing black-box and optional conditional estimators where useful;
  targeted fidelity/gradient tests are more justified than bending the world to
  force a full-world Jacobian.
- Study recursive designer changes or automatic same-society adoption only with
  explicit authority, evidence and a new bounded protocol. These are not implied
  by a model emitting a valid new institution.

Only after the desired small-scale concepts are operational should larger
populations, horizons, seeds and method comparisons become the main expenditure.
