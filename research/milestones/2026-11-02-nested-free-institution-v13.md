# V13 finite goal: nested search and additional native institutional freedom

Status: active; prospective design and parallel implementation, no v13 native
inference yet.

The [frozen protocol](../protocols/campaigns/native-nested-search-v13.md) connects
free outer source/graph generation to an inner conditional expected-loss update
and a fresh native followup. The organizing system remains the design object;
whole-world differentiability is optional, not the research destination.

| Track | Completion evidence |
|---|---|
| Nested kernel | Durable 2→1→1 schedule per objective; IID sampling, sole LOO update, exact post-update replay and full own-history redesign |
| Native freedom | Opt-in source-controlled actual review-task routing and complete applied-plan lineage; original default-world equivalence |
| Bounded pilot | Two exact losses, at most eight original-world native attempts, fixed Qwen/population/years/seed/corpus |
| Independent analysis | Checkpoint loss/measurement, source/process/task/plan proof, all ties/failures, unchanged raw inventory and repeated audit |
| Existing game UI | English nested path and actual effects; editable local branch preparation distinct from execution/adoption; actual browser QA |
| Publication | Notes/status, actual comparison figure, source-bound tests and rendered/reviewed updated manuscript; verified main integration/push |

Useful invention and improvement are empirical results, not promised acceptance
conditions. More samples, arbitrary science laws, complete-world AD and a full
game are outside this finite goal. V12 remains complete, not rewritten.
