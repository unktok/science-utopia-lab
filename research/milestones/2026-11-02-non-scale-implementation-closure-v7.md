## Rules and evidence separation

- Technical validity, chosen loss, evaluation metrics and consent are separate;
  no undeclared merit/fairness/participation veto.
- Local fixed Qwen researchers only for authorized model-backed pilots; no paid
  provider API, new cloud execution or scale expansion. Engineering tests may
  script HTTP/corpus, but execute original scientific phases and isolated code.
- Old source/raw remain immutable. New live execution uses its own clean pin.
- New actor/operation algorithms remain extensible primitives, not a fixed
  catalogue of evaluation/funding/government institutions.
- A gradient through a represented operation is not a pathwise derivative through
  text generation, arbitrary Python or native opaque reactions. Missing calculus
  is not fixed by freezing researcher-model weights.
- Automatic strategy updates are implementation evidence, not proof that the
  designer improves. Negative/no-change outcomes are valid completed experiments.
- Existing computational/capability limits are explicit; no silent clipping,
  source repair, success filtering or invented failed-world cost.
