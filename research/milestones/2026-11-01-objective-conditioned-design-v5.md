# Objective-conditioned institutional design v5

Updated2026-11-01. This milestone follows the v4 inventory; it does not rewrite
failed experiments or replace the original researcher world with a miniature.

## Project goal, not just today's pilot

Treat the system organizing science as a design variable. Fix an explicit loss,
then search parameters, implementation algorithms, new institutions/protocols,
connections and execution rules; change the loss and study how the resulting
systems and search paths differ. Black-box, gradient and hybrid methods operate
on these composable design freedoms. The original Science Utopia researcher
world is the minimum contained example, not the desired expression ceiling.
Expose the same system and evidence through an English cyberpunk pixel-art UI.
Long-term redesign may run within the same persistent society and ultimately
improve the designer itself; these are separate claims to establish.

## Concrete implementation in this iteration

1. Scoped, explicit authoring IR. The model writes free Python, ports, payload
   schemas, optional memory, node order, every input reference and every export.
   The compiler namespaces local names and allocates phases inside the actual
   cut. It inserts no unspecified semantic connection and no host algorithm.
   Invalid code is not manually rewritten into a supposed model invention.
2. Actual feedback-conditioned revisions. Initial host source is withheld.
   Subsequent prompts include the exact generated incumbent and up to two prior
   generated candidates with their actual loss, code, schemas, graph and order.
   A candidate that loses to the baseline is still visible as negative feedback.
   The controller retains the best declared-loss observation as the next parent.
3. Two independently specified losses. Throughput is `-A`; net-reviewed utility
   is `3.25*A-Q+0.05*R`. Q uses actual raw peer-review scores, not the institution's
   self-written final score. Coefficients are illustrative engineering values,
   not a validated science-policy welfare function. Reject-all is legal under a
   loss rewarding it. No implicit fairness/activity/quality promotion veto.
4. Exact common initial trajectory. A completed physical baseline is rescored
   for the other logical loss only after checkpoint hashes, actual model/corpus/
   source/seed binding, events, run/measurement bijection and independent metric
   reconstruction agree. Logical rows are not independent physical replications.
5. Durable joint campaign. One baseline and two adaptive slots per arm, at most
   three technical drafts per slot. An exhausted technical budget gives null
   loss and halts that arm, not the other arm. Infrastructure/integrity errors
   propagate; exact saved pending work remains available for restart. Per-arm
   terminal receipts expose both observed and declared budgets.
6. Separate fresh-native distribution-gradient experiment. Complete new native
   forward costs feed exact log-probability autograd/REINFORCE. Frozen-bank
   probability fitting remains separate historical evidence. Neither operation
   supplies a pathwise input-response Jacobian through the LLM/native world.
7. A new native action capability beyond publication/context delivery. Arbitrary
   connected institution code chooses resource-transfer commands; a native
   consumer changes actual author objects, classified ledger legs and later
   funding prompts. Exact per-leg representability, positive distinct-actor
   transfers, atomic batch validation/rollback and global replay identity are
   technical contracts, not an allocation algorithm or policy veto. Six-year
   scripted lifecycle, delayed cold restart and independent adversarial review
   pass. This is software evidence, not live-Qwen allocation benefit or a full
   treasury/actor/process ontology.

## Claims that remain separate

| Original goal | Implemented basis | Evidence still needed |
| --- | --- | --- |
| Objective-conditioned black-box system optimization | Persistent ask/tell, parameter held-out study and completed two-loss native code/graph feedback | Broader consequential process changes, richer explicit objectives and scientific evidence beyond proxy success |
| Non-catalog institutional invention | Free sandboxed Python/protocol/graph; four exact externally authored native candidates including an executed two-node protocol | Useful nontrivial institutions and richer semantics, not novelty inferred from all-accept/threshold or a node count |
| Freely composed science-system architecture | SystemSpec graph, generic runtime, original native domain adapters and new conserving-transfer capability | Further consumed actor/workflow semantics; hidden annual frame dependencies; wider live generated cuts |
| Gradient optimization without simplifying the forward world | Hard/soft local programs; full-native-cost score-function methods; transition representation with recorded failed fidelity | Faithful broader represented input-response dynamics; derivative fidelity and optimization benefit, not only autograd correctness |
| Persistent redesign and eventual self-improvement | Durable same-society migration and cold restart | Objective-conditioned live adoption, changed future scientific behavior, improvement of the designer itself |
| Game-like scientific-system interface | Original pixel-art city/foundry, replay, graph editing, explicit missions and real-job round trip | Browser migration, stronger play feedback and richer game experience |

Today's experiment intentionally edits a native selection region and charges
simple observable review/publication proxies. That is a small executable test
of the general concept, not a claim that selection is the entire science system
or that these two proxies should become the final research objective. Scale-up,
new seeds and equal-budget optimizer comparisons remain deferred.

The general graph runtime supports more than this authoring route. Current
native region proposals still require recorded contexts for an existing cut,
one to six nodes, at most32 edges and a zero-delay ordered DAG inside that cut.
Native annual stages run once in phase order, not arbitrary event-driven fixed
points; research/submission/funding still share private frame state. Actor-type
and invariant declarations do not implement new actor behavior or arbitrary
executable global invariants by themselves. These are concrete non-scale
limitations to remove, not missing seeds. The new transfer capability expands
one real action vocabulary without claiming to solve the entire ontology.
