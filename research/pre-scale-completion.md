# スケールアップ前の終了条件

2026年11月9日。ユーザーの「スケールアップする前までにやるべきこと全部」に対応する作業台帳。
前日の計画・既存データ分析を、実装と有限の小規模検証へ進める。
改善、異なるwinner、勾配優位、設計者の自己改善、現実の科学政策への一般化は合格条件にしない。

| 項目 | 終了条件 | 現在 |
| --- | --- | --- |
| 提出と実行期限 | 数値専用のliteral提出、既存自由code/graph、期限・中断・再生を実backendとscripted native consumerで確認 | 数値2/2実backend・cold replay成功。code/graphは次source確認が残る |
| 目的と測定 | T/Eを小規模対象、Cとraw成分を診断とし、law固定domain・seed・参照・選択・費用を実行前に固定 | draftから固定へ進める |
| 情報機構 | 元worldでM0/M1/M2/M3を作り、経路と実入力を確認し、有限の小規模比較を実行・解析 | scripted経路5件pass。source215311cで12world開始、初回索引構築中 |
| 自由制度の閉ループ | 同じsourceで数値／code／graph／uniformの目的別pilot、選択固定、未使用条件評価を閉じる | 未実行 |
| 勾配の接続 | 明示した設計分布とnative評価の対応、更新後のforward、無勾配対照を有限scopeで確認 | 過去実装・実測あり。次source接続を確認する |
| 継続社会 | 元worldのcheckpointから実際に制度を導入し、state・資源・memory・pending情報の保持を検証 | 既存基盤あり。次scopeを確認する |
| 検証可能な活動 | 既存worldを包含する、実際の計算・検証・訂正記録とconsumerの最小拡張。科学的発見の主張とは分ける | 独立したnative count検証・訂正・実入力まで19件pass。科学論文の真偽判定ではない |
| UI | 実験の実記録と制度・経路・失敗を英語UIで見られ、未実行draftと区別できる | 既存UIに今回の記録を接続する |
| 分析・原稿・再現 | 全試行・費用・作用・限界を記録、図と原稿へ反映、生成・検証を再現する | 未完了 |

新しいnative実行はcleanでsourceを固定した実験worktreeから行う。開発は別worktreeとする。
モデルは承認済みQwen3-8B／ローカル35Bのまま。外部サービス、新モデル、追加費用、公開／pushは含めない。
提出適合性が不明なまま大きなauthoring campaignを起動しない。失敗枠を裏で補充せず、修正と再検証は新source・新protocolで明示する。
研究上の不成功と実装不良を分け、完了していない項目を「準備できた」と言い換えない。

[前段の小規模案](protocols/campaigns/objective-system-mechanisms-pilot-draft.md)の70worldは上限案であって、一括起動はしない。
各段階の実行範囲、開始・終了、追加がある場合の有限予算をこの台帳とSTATUSへ記録する。
