# Closed information study observations

This directory retains all twelve four-year world observations, nine paired
differences, component costs and the original hard-selector trace diagnostic.
The experiment uses unchanged source215311c, five fixed Qwen3-8B researchers
and three development seeds. The source-bound full audits produce identical
bytes; their content hash is
`73658208283b002bc297f6f1ba0a4f59fd1257bf3509b2eae7a227da8c6b57e4`.
Raw requests, model replies, checkpoints, corpus and model weights are not
copied here. These local research artifacts are not public-release clearance.

`report.json` contains measured A/Q/R, resources, activity, history deliveries,
actual first direction-input years and all paired descriptive loss differences.
`costs.json` separates scientist usage, numeric readiness and role loads; unknown
load token counts remain unknown. Cached counts and overlapping timing aliases
are never added as independent compute. `selector-diagnostic.json` binds a
read-only original-compiler replay of48 recorded annual tensor traces. Its one
threshold-equality acceptance and11 all-rejected worlds are not counterfactual
interventions or optimizer results.

The corresponding PNG/SVG are under
`paper/figures/pre-scale-information-v1/`; `manifest.json` binds their exact bytes
and the retained report. Rebuild from a committed checkout with the existing
approved uv-managed project interpreter:

```text
.venv/bin/python -m scripts.reports.pre_scale_information_reproduce_v1 --output <fresh-directory>
```

The command recomputes all36 T/E/C cross-scores, condition means and nine
paired differences from retained measurements, then regenerates identical
report/PNG/SVG bytes and the twelve-row manuscript table body. It performs no
model call, native world, generated-code execution, dependency download or
original raw audit. Full re-audit requires the original raw inventory and the
pinned original-source audit adapter; numerical rebuilding is not fresh model
replication.
