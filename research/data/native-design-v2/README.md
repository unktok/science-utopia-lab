# Closed V2 numerical projection

This directory retains the complete closed-audit **report projection**, not the
714MiB audit, raw response journals, corpus files, weights or an experiment copy.
The deterministic gzip archive is712629 bytes; decompression restores the exact
7588874 report bytes. The manifest binds compressed/decompressed/file/content,
original audit and experiment-source hashes. Nothing is filtered, rounded or
reclassified in compression. Selected executable designs and audited action/
cost/lineage summaries remain as in the report; no institutional source is run
by numerical rebuilding. This is a local research artifact, not rights/anonymity
or public-redistribution clearance.

From a clean committed checkout, with the existing project environment:

```text
python -m scripts.reports.native_design_reproduce --output <fresh-directory>
```

Use the approved uv-managed interpreter, never Apple Python. No model, generated
program or simulator is called; no dependency downloads are attempted. The
command regenerates the exact search-table data/TeX, both search figures,
native-width common-score figures and all18 paired-reference figures. It
rejoins all120 rows, exact ties,90 physical evaluation jobs and19 shared labels
against retained manuscript data. It also recomputes462 T/C/E values from
measured A/Q/R for64 search plus90 evaluation forwards. Tiny independent-sum
IEEE roundoff is reported, never used to revise selection or audited values.

Resource output rechecks the **retained aggregates**, not the omitted individual
raw usage records. Cache counts remain subsets,293 role-load token counts
remain unknown and overlapping timings are not added as separate compute.
The compact paper-evidence file binds their original full cost projections.

The command is numerical reconstruction from retained observations, not a new
raw audit, external replication, fresh-machine model reconstruction or a proof
that another LLM inference run would produce the same responses. Full re-audit
needs the access-controlled raw inventory and pinned order adapter; fresh
inference additionally needs the models/corpus/backend and has the disclosed
35B upstream-recipe gap. No archive is uploaded by this command.
