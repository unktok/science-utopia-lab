readout retained outside Git. Large model responses/caches and the corpus are
not committed here.

`systems/` contains the exact two reference and six submitted SystemSpecs,
including failed C0. `selection.json` is the exact original sealed selection,
not reconstructed from displayed rounded losses. The [file manifest](systems-manifest.json)
binds every byte and the chosen system labels. U1 equals the strong reference
byte-for-byte because it explicitly retained that parent. No model output is
repaired, omitted, deduplicated as an independent run or relabelled successful.

These JSONs contain literal authored Python and typed graph declarations, not
host-executable trusted instructions. Parse with SystemSpec and use the
original protocol's sandbox/native execution boundary; never eval/exec source
on the host. The broad library is not limited to these observed programs.
Correct parsing is not proof that arbitrary runtime branches are valid.

This preserves executable institutions for collaborators without regenerating
the designer's proposals. It does not by itself reproduce inference, complete
a clean-machine installation, identify the unresolved designer upstream
revision/conversion, supply unused evaluation or establish publication readiness.
