# Conditional command response on four actual native input frames

This is an analysis of the closed planning pilot's original R7 inputs, not a
toy scientist world, an alternative four-year trajectory or scalar-loss search.
At clean analysis source `056f99140f5f77be2f2f0f67d68c4e02c6721887`, the
unchanged archived allocation artifact runs in its original Docker image on
all60 already declared integer reserve values for each of four recorded years.
All240 calls complete; the four reserve21 results exactly match the originals.
The matching original cold audits and entire raw inventory are checked first.

Only the one input parameter changes. Each year otherwise retains the full
actual recorded native input, not a simulated continuation from other reserves.
Results are requested commands, not newly committed native transfers or losses.
The live designer and queued numeric comparator do not receive these outputs.

The empty command output recurs in disjoint low/high intervals; those intervals
are kept separate. On the year3 input, reserve18 requests15 units for3 recipients,
reserve19 requests10 for2, reserve20 requests3 for1, reserve21 requests5 for2,
and reserve26 requests none. This is not a monotone response. It does not show
that18 or any other value optimizes scientific outcomes.

`report.json` retains original input hashes, source, actor input projections,
all240 rows and exact equal-command intervals. `response.csv` is the compact
numeric projection. `manifest.json` binds those files and the
[PNG/SVG figure](../../../paper/figures/native-reserve-command-response-v1/).
Full commands, attempt journals and execution receipts stay in local outputs.
The figure's dotted lines locate the existing reserve10/21 controls, not newly
selected optima. Equal observed commands do not imply global policy equivalence.

`year3-realized-ledger.json` separately joins the original reserve21 commands
to five actual founder balance records: opening90, annual costs50, grants20,
closing60, with zero accounting residuals. Four founders remain active. The
one at balance1 is removed by the inherited post-award positive-balance<=10
attrition rule; a different1-unit pre-award founder receives20 and closes at21.
This is a realized native path, not outcomes for the other59 reserve values or
a newly imposed participation/fairness/adoption constraint.

The [component](../../components/native-reserve-command-response-v1.md) and
[verification](../../results/native-reserve-response-verification-v1.json)
separate these scopes, actual execution and software tests. Analysis used
shared local compute while the live study continued; it is not a dedicated
hardware-speed benchmark. No model call, native world, optimizer feedback or
original experiment input is added or changed. Scientific gain is not inferred.
