## Hypothesis, not an expected winner

Ask whether changing when already budgeted funding/allocation occur relative
to annual costs changes native trajectories and T/U, without changing money
supply, scientist model, corpus, project durations, output limits, cost/award
amounts or native phase implementations. Observing the actual post-funding
world differs from reusing a stale pre-funding artifact. Native preconditions,
signal/data wiring and exactly-once scientific effects must still hold.

This requires a separate explicit workflow-authority domain, original-instance
regression and scripted native full-path checks before any scientific dispatch.
Keep the old fixed-calendar guards and active studies unchanged. A small
prospective comparison can hold source/numeric parameters fixed and vary graph
order alone. A hand-designed control is not autonomous invention; an optimizer
must separately show actual proposals, scalar feedback and selection. Failure
or no gain is legitimate, never a reason to repair/refill or hide a candidate.

This addresses the missing actual process-design comparison, not another larger
run of unchanged accept-all source. It may reveal an artifact of the simulator's
attrition/timing convention rather than real scientific improvement. No new
model call, world dispatch or hidden loss constraint is introduced by this note.
