# 目的条件付き科学制度と情報経路の小規模実験案

2026年11月8日。**検討用protocol。未実行であり実行可能な設定の凍結前。**
研究計画の具体化を目的とし、承認済みの長時間campaignや新モデルの利用許可とはしない。
[全体の判断計画](../../publication/research-questions-and-decisions.md)と
[既存データの追加分析](../../results/native-design-objective-landscape-v1.md)を前提とする。

## 研究質問と仮説

中心質問は、目的の違いが、科学を運営する制度の情報経路・状態・配分ルールと、その後の行動をどう変えるかである。

| 仮説 | 判別する比較 | このpilotで言える範囲 |
| --- | --- | --- |
| 過去の研究履歴に応じた情報が次の行動を変える | 個別の履歴に応じた情報と、同形の非適応情報 | 指定した期間・world・受信者での効果 |
| 経路の追加が作用する | 同じproducerで経路あり／なし、または遅延あり | 設定した経路の介入差。trace到達だけではない |
| 目的が制度選択を変える | 同じ初期条件と方法で異なるlossを探索 | 有限の試行で選ばれた制度。異なる勝者は必須でない |
| 構成の自由度が有限探索に役立つ | 数値、固定graph code、code/graph | 空間と提出経路を含むend-to-end結果 |

差が出ない対立仮説も残す。情報が既存memoryと重複する、受信者が使わない、既存世界のボトルネックと無関係、二年では効果が出ない、目的が単純な制度を既に十分評価する場合がある。
各仮説の有意差を全て要求する試験ではない。小標本から一般的な手法順位を結論しない。

## 固定する世界と設計対象

元のScienceUtopia研究者世界を使い、五研究者、固定Qwen3-8B、文献・retrieval・review parser・measurementを共通にする。
計画候補のhorizonは四年。元の1〜3年projectと、前期の記録が届いた後の行動を扱うためであり、長期の科学的価値を検証する期間ではない。
実行source・corpus期間とhash・backend・model alias・測定器は実行前に固定する。

第一候補は、既存の計画、publication、review、資源の記録を読み、次期の研究者contextに接続する履歴依存の制度である。
必要なら情報の受信先や保存stateを新しいnodeとsourceで定義できる。
資源配分は別の一軸として後続に置き、最初からcontextとtransferとproject期間変更を同時に介入しない。
査読機構だけを最適化する限定研究にはしない。

このpilotは物理的な研究生産の法則を固定したdomainとする。
研究者weights、文献の時点、測定式、projectに必要な期間・費用をdesignerに直接書き換えさせない。
後に生産過程の設計を調べる場合は別domainで比較する。従来の期間変更結果を無効にしたり、悪いlossの制度を事後に除外する条件ではない。
publicationやreviewを省略する制度自体は、技術的に整合したconsumerがある限り許す。

## 目的と評価

pilotの出発候補は、既存の二つのloss `T=-A` と `E=-Q+0.5R`。
既存測定で実装でき、異なる誘因を説明できるための選択である。
EはV2で探索していなかった新しい目的armであり、V2の良かった二候補をその発見として扱わない。
C=`4A-Q+0.1R` は事後的に排除せず、診断として全候補へ併記する。

これらは科学的真実や福利の指標ではない。
「知識の被覆」「活動継続」「検証済み成果」等を中心目的にする方が研究質問に合うと判断した場合、main比較の前に測定を設計し、このdraftを明示的に更新する。
結果を見たあとに良いlossへ付け替えない。

診断はA・Q・R、native submissions、review coverage、final activity、資源、実際のrecipient、context、plan、source／state／wireの使用。
最適化へ使う情報と外側評価を分ける。公平性、目新しさ、参加維持などを暗黙の合否条件にしない。

## 段階Dで提出経路を切り分ける

新しい科学実験より先に、承認済みローカル設計者で最大八つの実バックエンドsessionを行う案。
既存の形式copy証明は流用せず、新source・profile・domainに束縛する。

| 課題 | session上限 | 調べる内容 |
| --- | ---: | --- |
| 数値の直接提出 | 2 | 六座標の具体的更新、範囲／型のエラー後の再提出 |
| 既存sourceの変更 | 2 | 新しい短いルールと、履歴付きの修正・提出 |
| 機構と配線の変更 | 2 | 実consumerへ接続する中間処理、schemaエラー後の提出 |
| 共通の編集経路による数値変更 | 2 | 直接提出経路との違い、一般的なcode編集への逸脱 |

session当たり最大16action、合計最大128action。実transportの既定案はconnect10秒／read900秒、context40960、output8192、thinking off。
これは最速設定の主張ではない。sourceと実際の要求token・時間に適合するかを開始前に確認し、session全体の期限と中断・記録方法も実装・固定する。
未実装の期限を有効だと扱わず、単一read timeoutを全sessionのwall上限とも呼ばない。
外部サービスや新モデルを自動採用しない。

履歴付きfixtureは明示的に診断用であり、科学的な実測履歴を捏造しない。
全案のliteral source、raw request／response、終了理由、消費量を保持する。
型の正しさと静的検証だけでは十分でないため、scripted研究者応答で実consumerまで到達する技術的試験も行う。これは新しいQwen科学実験ではない。

失敗があれば八sessionの記録を閉じ、原因とprospectiveな修正を分ける。
同じbudget内の明示的repairは許すが、失敗したsessionを再試行で置換しない。
実バックエンドの適合性が不明なまま段階Oへ進まない。

## 段階Mで機構の作用を比較する

自動発明の前に、同じsource interfaceで四つの手作業制度を比較する。

| 条件 | 内容 |
| --- | --- |
| M0 | 現行のmemory／contextのみ。追加経路なし |
| M1 | 履歴から生成した、研究者ごとの具体的情報を次期へ届ける |
| M2 | 同じmessage schema・長さ予算の、受信者の履歴に適応しない情報を届ける |
| M3 | M1のproducerを保持し、接続を切るか追加一年遅延させる |

M3は切断と遅延の両方を後から試すのではなく、どちらか一つを実行前に選ぶ。
同じproducerを動かすだけの費用と、届く情報の効果を分ける。
M2の文面も行動に影響しうるため、完全な無作用placeboとは仮定しない。
recipient数、message上限、追加LLM呼出、計画・資源・採否の権限を揃える。初回は追加の研究者LLM呼出を増やさず、既存の入力へ接続する。

四条件×三development seedで最大12world、各四年。
同じ時点の介入前checkpointを使う場合は全入力の同一性を確認し、介入後はfresh生成する。
介入後の別条件の応答を再生して対照を作らない。
各seedの全観測とpaired差を報告し、三seedで決定的な因果一般化や統計的優位としない。

作用経路が到達しない場合、機構の科学的無効性ではなく実装・接続の問題として切り分ける。
届いて差が出ない場合も、同じ12worldを完遂して閉じる。効果が出るまで文面やseedを追加しない。
手作業制度を自動発明の成功例にしない。

## 段階Oで目的別の自動探索を比較する

二目的×四提案policy×二世代で最大16候補枠。一つの共通development world seedを使う、探索の成立をみるpilotである。
候補ごとに一つのfresh四年worldを実行する。初期観測と同sourceの参照は最大六worldを別に計上する。

| policy | 許す変更 |
| --- | --- |
| LLM数値 | 意味と実consumerを固定した座標のみ。段階Dで検証した直接提出 |
| LLM固定graph code | 同じ数値と、同じ情報／権限を持つ既存sourceの変更 |
| LLM codeとgraph | source、機構、state、配線、順序をpilotのcapability範囲で変更 |
| uniform数値 | 同じ座標domainの事前固定した独立sample |

固定graph codeが必要な情報と操作へアクセスできるなら、同じpolicyを一つのnodeへまとめて表現できることがある。
その場合、graphの優位性や表現不可能性を主張しない。構造上の分割の探索・費用上の効果とする。
情報制約そのものを比べる研究では、誰が何を読めるかを明示した別のdomain差として扱う。

参照の候補はlegacy、editable initial、review付き全採択、reviewなし全採択、reviewなし全却下、段階Mの固定機構一つ。
同じsource・設定・介入・seedで明示的に同じ観測を共有できる場合のみ共有し、共有分は物理world数を減らす。
別sourceの歴史的な良い候補や、他armの未来のlossを無断で初期bankへ入れない。

初期best、同点、悪化、保持、null、全費用を保存する。
失敗を大きなlossや0にせず、予算終了時に初期を含む各armのbestを固定する。
二世代は探索の成立と失敗の診断であり、sample efficiencyや手法優位性の実証ではない。

## 段階Eで選択後の挙動を評価する

最大八つの選択制度と四つの事前指定参照を、三つの未使用seedで評価する。最大36物理world、四年。
参照四つの選択は段階Oの結果を見る前に固定する。六つの開発参照を都合よく結果から絞らない。
同じexact policyを明示共有すれば実行数は減る。共有を追加標本にしない。
同点の全IDを保持し、代表の選び方は事前の時系列規則に固定する。全同点を評価したと誤記しない。

選択manifestを最初の評価より前に保存する。
全制度を共通T・E・Cとraw成分で相互採点し、評価から再設計やwinner変更へ戻さない。
小標本なので全値・効果量・paired差を主とし、method順位や「科学が良くなった」という結論は出さない。
不足した測定値は未知のまま残す。

## 費用上限と実行順

| 段階 | 科学world上限 | 設計者session上限 | 意味 |
| --- | ---: | ---: | --- |
| D | 0 | 8 | 実backend提出とscripted技術試験 |
| M | 12 | 0 | 手作業の機構比較 |
| O | 16候補＋6参照 | 12 | 2目的×LLM3policy×2世代。uniformに設計者呼出なし |
| E | 36 | 0 | 最大12制度×3seed |
| 合計上限 | 70 | 20 | 各段階を別々に開始判断。失敗枠は補充しない |

70worldを一括で今から回す計画ではない。world単価も既存二年worldから決め打ちしない。
段階Dの提出適合性、段階Mでの実際の作用と時間を見て、このdraftの次段階を開始するか判断する。
肯定結果が出ることを進行条件にしない。一方、問いに必要な作用を一度も観測できない構成のまま大規模化しない。
read timeout、全session期限、worldの安全な終了・checkpoint、source、loss、全参照、seedの具体値、topic／corpus期間は別途凍結が必要である。

## 分析と反証

1. **目的の影響**：選択制度、全探索経路、相互採点、raw A/Q/Rと行動。異なる制度が選ばれなくても保持する。
2. **機構の影響**：実consumerと到達履歴、M条件のpaired差。複数の同時編集から単独効果を主張しない。
3. **提出能力**：全枠の完走率、finish理由、消費量。完走例だけの平均を無条件の性能としない。
4. **自由度の使用**：許可した空間、実際の差分、実行されたbranch・state・wire。graph変更なしも結果である。
5. **不確実性**：三seed、単一探索履歴、同じpolicy共有、fresh応答を区別する。大きい推定誤差を成功・失敗の決着に使わない。
6. **費用**：designer、scientist、role load、container／hostとwallを別に記録。未報告量を0としない。

新制度が勝たない場合も、目的の誘因で説明できるのか、同じ情報を既存codeで表せるのか、探索が出せなかったのか、世界が反応しなかったのかを分ける。
分離できない場合は「原因不明のpilot」として閉じる。重要な否定結果だと格上げしない。

## 本比較と勾配へ進む判断

このpilotだけをtop conferenceの決定的な実証とはしない。
中心の問いに答えられると判断した段階で、探索履歴と環境反復を分けた本比較を別途設計する。
実測の変動、意味のある効果量、総費用から反復数を固定し、過去に良かった条件だけを残して規模を増やさない。

勾配比較はこの70worldへ暗黙に追加しない。
構造・sourceを固定した一つの分布に限り、同じ評価予算の無勾配法とLR／LOOまたは補正付きcontrolの一方式を比べる別protocolにする。
全世界Jacobian、LLM重み更新、新しい推定理論を必要条件にしない。
有限batch後の実際のnative更新評価と、反復時の推定量の安定性を測り、単一の改善／悪化を期待勾配の証明・反証にしない。
