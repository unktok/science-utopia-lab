# Native resource opportunity support assay

## Question

Can conserving transfers at an actual pre-cost opportunity change researcher
activity or publication outcomes under two explicit initial endowments? This
finite developer-controlled assay tests support for a later objective-conditioned
institution search. It is not autonomous institutional invention, optimizer
comparison or a main-conference result by itself.

The original five Qwen3-8B author-capable agents, other native agents, four-year
calendar, original2016–2019 literature, research, collaboration, submission,
review, publication, grant and activation rules remain unchanged. The native
annual project cost is10; no grant income is guaranteed. Initial endowments,
not scientific production laws or candidate merit constraints, are varied.

## Four prospective worlds

Use development seed61001, reused from earlier development, never held-out.
The two original `balanced_two_band` blueprints have base funding30 and60.
With five founders they assign `[15,15,40,40,40]` and `[30,30,80,80,80]`, in
the seed-determined actor order, totaling150 and300 respectively. The assignment
does not depend on outcomes or institutional condition. Both include the same
original resource event ledger.

Within each endowment compare two precisely specified systems:

- Both start from the same M1 information institution with original reviews and
  developer accept-all selection. Both add the same Python producer, state,
  transfer receiver, schedules and computation.
- The producer reads the actual submission-phase native snapshot, immediately
  before annual costs. It moves whole units from active authors above the floor
  of the active-author mean to those below it, with deterministic resource/ID
  tie-breaking. This is an explicit hand-authored reference, not a normative
  definition of good science or a generated candidate.
- In the disconnected condition only the producer-to-transfer-receiver edge
  is removed. No transfers execute. In the connected condition the existing
  conserving native consumer applies exact representable debits and credits.
  No cash is created, no inactive author is reactivated, and no project is
  shortened. The algorithm can transfer nothing when no command is needed.

Dispatch order is base30/disconnected, base30/connected, base60/connected,
base60/disconnected. Retain all four outcomes. No favorable endowment, actor,
content or seed is selected after observing these outcomes. Different initial
endowments are different environments; the connected/disconnected contrast is
the within-environment intervention. No graph-syntax benefit is identified.

## Execution and budget

Run once from an exact clean committed worktree after the preceding228-response
observer is normally closed and its writer has exited. Use only existing local
models, the pinned no-network code executor, offline corpus and serialized
inference. No designer-generation POSTs, model acquisition or external services.
Each world has at most1024 scientist HTTP attempts: at most4096 for four worlds,
plus four separately recorded scientist-load requests. Runtime safe points use
a declared7200-second wall allowance per world. The existing model transport
keeps its declared120-second read limit and native semantic-attempt policy;
do not silently change it during execution.

Any unknown inference completion stops later dispatches. A failed control world
stops this assay without retries or replacement; preserve its partial checkpoint,
requests, code attempts, null loss and the unexecuted later slots. A normal
closure requires four complete worlds. No weak result triggers extra worlds.

## Observation and next decision

Record original A/Q/R, final active founders/resources and all annual
founder-resource/activity states. Reconcile classified ledger legs and every
conserving transfer; verify their code/context/source lineage. Compare full
scientist request payloads before the first transfer, and retain changed
downstream inputs rather than inferring behavior from command logs alone.
Original Q remains an endogenous review opinion, not scientific truth.

The dispatch loss is the original throughput loss for bookkeeping; this assay
does not search or select policies under any objective. Final participation is
a diagnostic, not a veto on output or a hidden fairness condition. Both better
and worse outcomes are retained. Report all four physical worlds and their
within-endowment differences descriptively, not independent optimizer histories
or a precise population-level causal estimate from one seed.

After closure, determine whether the original resource/participation axis offers
a consequential objective/action opportunity. If it is flat or transfers do not
help, retain that result and do not declare a successful new main question.
A later search requires its own loss, authority, strong controls, finite budgets
and unused evaluation split. Nothing here changes past losses or selections.
