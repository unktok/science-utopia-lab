# V17 a1 post-repair native design and feedback pilot

2026-11-04. The user authorizes the next goal: run the repaired system through
two objective-conditioned generations in the original researcher world, then
report candidate changes, measured losses and feedback-guided next designs.
This protocol is prospective, before any new author or scientist generation.
It does not replace the V14/V15/V16 failures or transfer their costs/results.

## Fixed research problem and freedoms

Keep the disclosed original-world `open_native_system` seed (19 nodes,27 wires),
five balanced independent researchers, one conference, two simulated years,
four-year real public corpus, development seed42 and fixed Qwen3-8B weights.
Retain the existing Docker image, model and corpus hashes in the frozen plan.
No anonymous/numeric toy world or human-authored replacement institution.

The design space remains the whole executable SystemSpec: parameters, code,
mechanisms, message/port schemas, wiring, schedules and bounded processes.
No policy menu, quality/fairness/novelty/promotion veto or forced change.
Keeping the parent and observing an equal or worse loss are legal. Static
validity is separate from merit and optimization loss.

Two separate own-history blackbox arms use the existing frozen LossSpecs:

- Throughput: `native-joint-v5-throughput`, L = -A (accepted decisions).
- Reviewed production: `native-reviewed-production-efficiency-v13`,
  L = -Q +0.5R (accepted peer-score sum and review-record cost).

These are illustrative optimization targets, not endorsed societal welfare
measures. Cross-scores may be reported but do not change either arm's objective.
No held-out confirmation, method-superiority or causal objective effect claim
from this small development-seed run.

## Finite budget and stopping

Two generations/native slots per arm:4 scheduled native slots maximum. The
existing staged-v15 kernel gives16 tool calls/generation,2048 output tokens/call,
so at most64 new designer POST attempts. Temperature .2, thinking off, context
32768, fixed request/step-derived seeds. Scientist output bound768 and existing
semantic parsing limits remain unchanged; log every physical scientist reply,
wire request and code execution. Scientist HTTP/cache/checkpoint replay is
separate from generating a new replacement trial.

No author transport retries. Interrupted intent consumes a step without
redispatch. A failed generation consumes its one scheduled slot with null loss
and no native world; it is never substituted with a baseline. Invalid finish
does not execute source or a world. Native technical failures remain explicit;
no silent penalty loss, budget increase or failed-slot replacement. Only this
arm's actual current-revision observations/failures reach its next generation.
If no world was evaluated, there is no invented measured loss to feed back.

Stop at the declared4 slots or a technical abort. A terminal scheduler does not
prove four worlds ran or that the operational research goal succeeded. If the
goal is not reached, retain this revision, diagnose the exact cause and record
any next source/budget prospectively; do not call failed attempts completion.

## Outcomes and evidence

For each generation, report independently: valid explicit finish or failure;
literal source/graph/parameter/distribution changes; actual sampled candidate;
native execution/technical status; A/Q/R, objective loss and costs; exact own
observations supplied to the next design. A new name/hash or unused field is not
useful invention. Structural change is not behavioral change, and behavioral
change is not improvement. The closest milestone is an actual valid proposal
→ original-world measured loss → next automatic design → original-world loss.

After the writer stops, perform two read-only source-matched audits and compare
hashes/inventories. No source execution, model call or raw correction in audit.
Publish compact paths/costs/lineage and interpretation. Preserve all unsuccessful
drafts and report any audit failure without rewriting them. Future scale-up,
held-out testing, game/paper updates and estimator comparisons are outside this
finite pilot unless separately authorized.
