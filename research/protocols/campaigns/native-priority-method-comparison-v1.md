Prospective development-informed method-screening pilot, not a main-track
finding, clean scientific intervention on representation alone or a guarantee
of improvement. Historical studies and their selections remain unchanged.

Compare uniform topic priorities, adaptive topic priorities and the approved
free-code/mechanism/wiring author under the same U/C objectives in the original
persistent four-year/five-founder researcher world. Reuse development seed61001,
the approved fixed Qwen3-8B scientist/model digest, exact corpus, original

## Strong common parents and restricted coordinates

Run three fresh reference worlds before any own proposal: the explicit all-zero
priority rule, its known terminal-consolidation version, and the literal
core-plus-related rule. The first two are visible selectable parents for every
method. The third is a disclosed comparison-only rule, not silently substituted
for a missing measurement. The terminal rule is already known to us: reproducing
its accounting gain is not a new discovery. Reference failure stops the pilot.

Each objective chooses the first minimum-loss common parent in declared order,
identically for every method/history. A numeric anchor must be byte-for-byte
the same canonical SystemSpec as its actual measured parent. No historical
loss is assigned to a newly constructed zero-anchor program. The complete
reference bank and all cross-scores remain recorded.

The restricted family varies only explicit priority weights in[-1,1] for every
displayed catalog topic. Original shortest duration takes precedence; weights
break ties, then lexical topic breaks exact priority ties. Source, graph,
schedule, eligibility, original durations and all other fields remain literal.
These are parameterization bounds, not an empirically proved optimum. The
free author may replace that rule and create source, mechanisms, ports,
protocols, wires and processes under the existing v6 native authority.
Restricted-family cost changes are not assumed possible; at fixed K the U/C
rankings are identical. Different objectives need not return different systems.

## Selection, cold verification and limits

At budget end select the earliest tied complete own submission independently
for every method/history/objective, or none. No reference fallback and no
novelty, fairness, activity or improvement veto. Preserve all attempts, all
reference/own cross-scores, paths, literal programs, input/choice classes,
technical errors and complete role journals. Code/graph changes alone are not
operative benefit. Independent optimizer seeds are not independent researcher
populations; shared seed61001 and common references remain explicit.

The original-source cold auditor reconstructs numeric asks/tells and parent
states, free-author calibration/proposal wires, every native physical world,
scientist transport/load proof, original critic measurements, complete slot
chronology, frozen selection and exhaustive world/cache/dispatch coverage.
Two separate audits and cost exports must match without model calls or code
execution. SCRIPTED full-path checks are software evidence only.

No unused-condition evaluation is part of this pilot. Freeze selected systems
before declaring/running a separate unused evaluation. Two proposals per history
are a small screening budget, not convergence, globally strong search or a
standalone demonstration of general method superiority. A flat outcome does
not establish an impossible search space; do not automatically scale it up.
Important differentiated findings and final submission readiness remain open.
