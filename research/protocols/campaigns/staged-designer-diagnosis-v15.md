Use the exact stored step2 provider payload for each G1 objective arm. Each
has two prior inspection actions and its exact own prior native loss. Keep the
model digest, original seed, world definition and numeric loss fixed. Ten
variants per arm give20 single-step POSTs:

The role intervention moves only trusted source constants, never source code,
world text or observed claims into authority. No variant supplies a candidate
institution implementation or an optimization answer. The labelled interface
control alone specifies a metadata edit; it must never be called invention.

## Bounded tool continuation

For the two combined-treatment first responses, permit at most5 additional
POSTs each: at most6 responses including the already counted first response.
Use the exact historical pure JSON/static interpreter, initial parent and
original request, starting after the same two historical inspections. Rebuild
the historical prompt and apply the same combined treatment after each step.
Stop on valid finish, unknown transport or incomplete/unparseable reply, or the
six-response diagnostic limit. No result-dependent replacement or extra budget.
The model's base per-arm sampling seed remains fixed in these continuations.

Literal edits are interpreted as JSON data and may receive static diagnostics.
Process creation and tool network calls are forbidden during interpretation;
generated Python is never imported, evaluated, sandbox-run or world-run.
The original16-step protocol's remaining-call count is not shortened to force
a finish for this diagnostic. An unfinished six-response trace remains unfinished.

## Accounting and causal scope

Total new budget: at most30 generation POSTs,2048 output tokens/POST,180s
timeout, zero transport retries, zero native worlds and zero source execution.
Each dispatch gets an exclusive intent file before HTTP; replies/costs/errors
are preserved. Unknown intents consume their slots and are never redispatched.
The source and complete payload plan are committed/frozen before generation.
Metadata GETs and current server version are separately recorded. No other
provider, larger researcher model or trained weights are introduced.

Compare next actions, useful versus repeated reads, edit/schema validity,
truncation and sustained progress. Changed actions in two contexts do not prove
general invention, improvement or scientific benefit. Same-seed paired input
interventions identify local input sensitivity, not broad expected effects.
The combined condition cannot identify the separate contributions of its parts.
If the current exact-input baseline does not reproduce the historical action,
report that limit rather than silently attributing all differences to a fix.
Do not confuse loss being available with the author having understood or used it.

Historical evidence is read-only and checked before/after diagnosis. Diagnostic
code, raw outputs and notes live on a separate local branch. No production
runtime change, main integration or remote write is part of this diagnosis.
