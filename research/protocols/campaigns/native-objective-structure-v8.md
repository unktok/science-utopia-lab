# Objective-conditioned structural institution exploration v8

Preregistered2026-11-02 before any v8 native inference. Original native research
is the forward world, not a simpler numerical replacement. Prior source/raw and
held-out seeds remain untouched. This is a development experiment, not validated
science policy, optimizer superiority or a claim of successful invention.

## Question and fixed budget

What executable institutions, composition/wiring changes and search paths arise
when the same open design interface optimizes different explicit objectives?
The optimized object is the system; the chosen loss stays fixed within an arm.

- Two arms, existing exact versioned losses:
  `native-joint-v5-throughput.json` minimizes `-A`;
  `native-joint-v5-net-reviewed-utility.json` minimizes `3.25*A-Q+.05*R`.
  A=actual accepted decisions, Q=sum of accepted raw-peer-score means,
  R=all actual review records. Generated final_score cannot manufacture Q.
- One development seed42; five original authors, original conference setting1,
  two native years, original four-year corpus. Fixed local Qwen3:8B researchers,
 768-token cap, thinkingfalse, serial HTTP via existing shared inference lock.
- Each arm has two source-generation rounds with two conditional IID design
  draws per round: EIGHT physical worlds maximum, not eight successful worlds.
  This adds an objective arm, not population/seed/horizon scale-up. No held-out
  evaluation, additional endpoint-validation worlds or model-weight training.
- Same initial developer SystemSpec and settings; every draw is a fresh physical
  world/cache. No shared trajectory is counted twice. Native randomness and LLM
  responses need not match; one-seed outcome differences are not causal effects.

## Search freedom and authorship

An externally authored arbitrary base patch, edit factors and continuous
coordinates feed the existing durable native adaptive hybrid search. The
source-authoring specialist is Codex (self-reported), NOT fixed Qwen researcher
authorship. No extra paid model API or generated host-code execution is allowed.
Every exact inbox request/response/consumption is retained.

Nodes, source, ports/protocols, explicit wires, schedules and process dependency/
branch/repetition rules may change, including removal of developer institutional
and tensor nodes. Original scientific phases and actual native actions remain.
There is no fixed catalogue of institution algorithms. No particular tensor ID
is required; differentiable-fidelity work is a separate explicitly labelled
track, not a reason to constrain this arm's architecture.

Source generation sees only its arm's exact objective, incumbent, past actual
losses, code and search updates. The root seed and all authoring source are
explicit engineering inputs, not discoveries. Learned-weight transport across
different vocabularies must be authored. Structural novelty is NOT a loss term,
veto or promotion rule. Identity, reject-all and unchanged systems are legal.
Repeated IID choices are retained rather than rerolled to force diversity.

Each arm uses the same hybrid settings. Native loss supplies conditional
discrete/Gaussian score updates and declared designer-selection heuristics.
These are not source-content or full-native/LLM pathwise gradients, nor evidence
of designer improvement. This experiment compares objectives, not optimizers.

## Validity, failure and reporting

All grammar options are statically checked, no invalid probability mass silently
dropped. All source/graph/protocol/runtime failures retain raw evidence and null
loss; no hidden quality/fairness/participation veto, fabricated penalty or
replacement inference. Missing authoring is a durable wait. Ordinary unexpected
driver failures stop and preserve state; any necessary repair gets a NEW source
pin/amendment, not mutation of a live worktree. Original parse-retry behavior is
recorded, not a new designer budget. One writer owns the output.

The independent audit replays generation/distribution history without inference,
remeasures eight native diagnostics from actual checkpoints, checks source/
protocol/edges/events/code contexts/replies and preserves every raw file hash.
Cross-score ALL completed draws under BOTH losses; select each arm's best using
only its own loss and earliest tie, preserve all co-best ties. This is common
development evaluation, NOT held-out or additional independent replications.
Show complete paths, actual node/edge/source changes, failures, selected
cross-scores and whether any best improves. Different objectives need not yield
different institutions. A lack of improvement/diversity is an honest result.

Completion requires executable changed topology to be exercised and verified,
the fixed objective-conditioned budget to terminate with failures retained,
independent audit, figures and current notes/paper/English interface. It does
not require beneficial invention. Pure helper demonstrations alone cannot be
substituted for this actual original-Qwen exploration. No numerical miniature or
artificially successful backward can substitute for native fidelity evidence.

Runner: `scripts/run_native_objective_structure_v8.py`; run only in a clean
commit-pinned experiment worktree. Separate gradient track develops native
response/fidelity representations with scripted provider software QA, clearly
separated from the eight actual-Qwen worlds.
