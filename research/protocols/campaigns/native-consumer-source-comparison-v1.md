## Scientific question, not another endpoint demonstration

Does exposing the original world's actual fixed consumers change what a local
designer can construct and improve under a declared institutional objective,
when compared with the same free editor, measured parent and probe access?
The central object remains the organizing system of persistent researchers,
not an agent prompt in an isolated task or an easier numerical substitute.

The earlier local search's valid edits, unused parameters, ineligible assignment,
read loop and parent retention are distinct observations, not a proven common
cause. The hand terminal rule establishes reachable C headroom, not that missing
consumer knowledge caused its absence from generated systems. The proposed
comparison tests an information package, not comprehension in isolation.
Added input tokens, attention allocation and changed stochastic outputs are
part of the treatment; equal output budgets are not equal measured compute.

Working hypothesis: literal fixed-consumer source can help an author connect
its own generated code to real effects rather than edit unused settings.
Falsification includes unchanged/inert paths in both arms, grounded proposals
that are invalid or worse, equal own losses, or apparent improvements explained
only by an already known rule. No positive contrast is required for validity.
This pilot alone cannot establish an important general result or main-track
readiness, even if it recovers the known terminal opportunity.

## What would still be needed for the publication goal

This pilot tests a concrete possibility rather than enlarging a previously
unchanged search. A positive result needs independent optimization histories,
strong same-authority search-method controls, more than one development regime,
selection-frozen unused evaluation and an explanation beyond a trivial accounting
incentive. A null can remain scientifically useful but is not automatically
important just because its logs are complete. Do not auto-scale or declare the
whole goal achieved from either outcome. Other useful free-system effects,
objective-conditioned designs and richer original-world extensions remain in
scope; this information intervention is not a replacement research objective.
