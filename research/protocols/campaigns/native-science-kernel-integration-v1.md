# Native research-world integration probe v1

Frozen before the first live execution. This is an integration probe, not a
policy optimization campaign or a claim of scientific improvement.

## Question and world

Can a generic SystemSpec execute the original researcher world and connect an
additional institution's new protocol to actual later Qwen researcher inputs?
The original world is a contained instance, not an expressiveness ceiling.
Preserve original population initialization, language decisions, papers,
SciEvo retrieval, review, publication, funding and longitudinal history.
Reduce population/time, not activity into numeric equations.

## Frozen execution

- Clean source commit, separate detached experiment worktree; record commit.
- One development seed: 1301; four years; five university researchers, one
  institution, one conference; fixed funding allocation. No held-out claim.
- Local Ollama `qwen3:8b`, record actual digest; expected installed digest
  `500a1f067a9f782620b40bee6f7b0c89e17ae61f686b92c24933e4ca4b2b8b41`.
- Explicit non-thinking, 768 output tokens, concurrency one, transport retries
  zero. Native phase retries two. These are prospective probe settings and
  not directly comparable with historical campaign timing/results.
- Existing original four-year SciEvo cache: record actual dataset identity
  and ordered document hash. No fixture corpus or replacement embedding rules.
- Baseline graph plus isolated programmer-authored research-commons Python
  node. It reads actual projects/papers and sends an optional replication or
  robustness suggestion. This is not LLM invention or an optimized institution.
- Local existing pinned Docker image; network disabled, no host mounts or
  credentials. Record source/spec/image identities through execution receipts.
- `scripts/run_native_world_probe.py` writes raw wire payloads, response cache,
  canonical replay, full native graph checkpoint and manifest outside Git.

## Gates and interpretation

1. Original-coordinator versus baseline-graph six-year deterministic QA must
   match scientific state, RNG and wire requests (same clock and replies).
2. Actual live native run completes all years; no silently replaced phase.
3. The new node consumes actual world observations and produces provenance-
   bearing messages; real cache-miss HTTP requests contain them in later years.
4. Final portable checkpoint restores the native kernel; canonical replay
   converts without detached graph references.
5. Record actual domain counts and timing as diagnostics only. No scientific
   loss, fairness veto, preferred institution or acceptance threshold is added.
6. Prompt delivery is not proof that research improved or even changed. No
   paired causal behavior comparison is planned in this probe.
7. Whole native-world autograd remains false: LLM, retrieval and discrete
   resource/publication transitions are explicitly opaque. Numeric-world
   gradients cannot stand in for this missing capability.

## Failure handling

Retain failed manifest and completed-response cache; never overwrite a run.
Use completed-year checkpoints as authoritative. In-flight domain side effects
are not transactional, so retry from a new Simulation restored to the last
completed year, not the mutated failed instance. Any source/protocol repair
gets a new commit/run directory and an explicit amendment before execution.
