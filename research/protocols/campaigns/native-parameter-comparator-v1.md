# Numeric reserve comparator in the original planning world

This is a prospective six-world numerical continuation of the closed14-world
planning T/U development pilot. The choice to run it is post hoc to that pilot,
not a preregistered treatment or unused evaluation. It does not modify the
independently running parent-presentation study. No actual inference is
authorized by the existence of this protocol alone: clean committed source,
full-path software verification and the finite prepare/run bindings are required.

## Question and common information

Can an ordinary numeric optimizer find a better reserve in an existing strong
institutional family, and how does its three-proposal trajectory compare with
the prior three-proposal free-program trajectory for each assigned loss?
This tests an operative alternative to code authoring, not a new algorithm.
Three proposals are a matched small budget, not an exhaustive or converged
search; do not advertise this alone as a globally strong optimized comparator.

Reuse the exact8 common reference observations from the normally closed
`native-planning-objective-loop.v1` study, two matching original audits and its
literal development-reference context. These were fresh in that original
study, not fresh executions here. Do not import its6 own outcomes into the
numeric optimizer or choose bounds/seed using their individual values.
The source, common bank, reused model/corpus/loss information and post-hoc
status must be visible in the comparison. Reused bank compute is reported
separately from six additional evaluator calls, never counted as newly run.

For each of T and U, rescore that common bank by the unchanged declared loss.
The first minimum in the original bank order is the literal numeric anchor,
matching the free method's initial parent selection. It is the only imported
incumbent. If it has no existing numeric reserve consumer/field, stop before
scientific dispatch and retain the coverage failure: do not substitute a
different family, insert a consumer, or pretend it was a numeric modification.
All8 references still appear as comparators, including any ties.

## Optimizer and finite budget

then bounded uniform mutations of the best completed own/reference outcome;
initial mutation scale.2 and the existing inverse-square-root decay apply.
The declared measured anchor is warmed in before the first proposal, without
fabricating an own suggestion or spending a new world. Exact JSON duplicate

evaluator slot or merges different programs because their scores match.

Two independent state journals are objective-conditioned, but one history
per objective is not independent optimizer replication. Interleave T0,U0,

the study; never retry, repair, salvage, refill or restart the consumed run.

Final selection is the earliest tied complete **own numeric proposal** under
its assigned loss, or none if all fail. The warmed reference is reported
