## Full goal and engineering hypothesis

Keep the full active goal: genuinely different LLM-authored scientific systems,
actual original-world evaluations under the selected loss, measured own results
returned to subsequent proposals and another native evaluation. Ending jobs,
writing a plan, retaining the parent or passing static checks alone does not
establish that goal. Scientific improvement remains an empirical outcome.

V21 is still running during development. Its completed throughput arm retains
the parent twice at`[-1,-1]`, despite explicit loss arithmetic and accepted author
notes. The G0 rationale still equates correct code with the objective. Its
reviewed-production G0 measures8 without changing the system. This motivates
separating institutional design intent from implementation review; it does not
prove the remaining V21 outcome, a general8B limitation or the proposed remedy.

The initial planner receives the exact loss and own numeric breakdowns plus
the current graph's mechanisms/ports/connections/schedules. The host withholds
literal parent source, parameter/state values and metadata from that frame.
The fixed model must propose its own intervention/hypothesis or justified
retention, rather than copy an implementation already in its context.

Store the exact plan as untrusted author memory. The subsequent editor can
inspect actual implementation bodies, perform arbitrary literal source/JSON/
graph/process changes, revise the plan or explicitly retain. No host-authored
policy, parameter value, code algorithm, wiring choice or new institution is
supplied. No plan text is executed or copied automatically into a candidate.

## Procedural and authority boundaries

For budgets greater than one, advertise planning on the first call, followed
by editing. Keep the full host ACTION_SCHEMA: a literal valid direct finish or
other tool action remains legal, so this is not a novelty/merit gate or implicit
candidate replacement. One-call sessions retain the existing direct finish
route. Planning consumes an ordinary finite author step; there is no free or
hidden extra generation. Finish still requires full static validity and an
explicit authored rationale. A plan-only session without finish fails normally.

The Python caller chooses the task; observed source/world/history strings may
not select a trusted role. Planner/editor wire reconstruction and frozen-source
audits bind the exact role and state history. Plans remain untrusted data in
editor context and provenance, not operator attestations. A stored plan changes
author memory, not the scientific SystemSpec or its measured merit.
