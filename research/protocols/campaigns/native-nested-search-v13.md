## Question and exact losses

Can the same open institutional representation support both externally authored
black-box redesign and a conditional expected-loss gradient update, and how do
two declared losses produce different systems and paths? The organizing system
is the optimization object; whole-world differentiability is not required.

Canonical arms, with exact checked LossSpec bytes/definitions in the run plan:

1. `native-joint-v5-throughput`: minimize `-A` (unchanged existing LossSpec).
2. `native-reviewed-production-efficiency-v13`: minimize `-Q + 0.5 R`.

A is actual accepted decisions. Q sums ORIGINAL integer-parsed accepted-paper
review means, not institution-authored scores. R counts actual review records,
not the legacy reviewed-paper counter. Both are illustrative, gameable proxies,
not validated scientific welfare. The coefficient rationale and limitations are
[explicit](../../objectives/losses/native-reviewed-production-efficiency-v13.md).
There is no additional fairness, quality, novelty or promotion constraint.

## Fixed world and eight-attempt budget

Keep five original native authors, two years, world seed42, four corpus years,
fixed Qwen3:8B weights and real native projects/papers/retrieval/resources/actions.
Serialize local inference with the existing lock. Do not replace the researcher
world with numeric dynamics or reuse researcher replies from another candidate.

For EACH objective, exactly these scheduled stages:

| Stage | Authoring / proposal | Native attempts | Update |
|---|---|---:|---|
| `initial-batch` | External complete free G0 vocabulary | 2 IID draws | Existing likelihood-ratio estimator with leave-one-out baseline |
| `updated-proposal` | EXACT G0 vocabulary at saved updated weights | 1 fresh draw | Forward only; no second update |
| `redesign` | External complete G1 vocabulary, given all own history | 1 fresh draw | Forward only; no update |

Total maximum: FOUR attempts per objective, EIGHT across both. No replacement,
hidden retry, additional final gradient or improvement-conditioned extension.
An invalid generation consumes its authoring slot and executes zero worlds;
technical failures retain null outcomes. If the initial update is unavailable,
the next scheduled proposal explicitly uses unchanged G0 weights; do not invent
a gradient or penalty. A later scheduled redesign may react to earlier failure.
Empty factors/coordinates, zero gradients, retained source and exact ties are
legal. Successful improvement is not a completion condition.

## Conditional gradient and free outer search

Reuse the existing categorical-logit / bounded-Gaussian-latent design sampler
and likelihood-ratio loss estimator. The two first draws are conditionally IID
at the same frozen vocabulary and parameters. Learning rate is 0.1. Preserve
latent draws, probabilities, score terms, LOO baselines, gradients and weights.
The post-update draw must replay those exact updated weights and use a distinct
draw identity even if factors/coordinates are empty. No gradient of generated
Python source, fixed Qwen weights, or the complete native world is claimed.

External G1 authoring receives all three own prior observations, source/graph,
draws, update/no-update reports, failures and every exact incumbent tie. It may
retain, replace or invent algorithms, nodes, protocols, ports, wiring, schedules
and guarded/repeated/dependent processes. It is not restricted to a host menu.
No other-arm/future outcomes are supplied. Provenance is self-reported external
Codex authorship, not authenticated Qwen source invention. Any pre-consumption
technical repair retains the draft/error; consumed definitions are immutable.

Generated code runs only in the pinned networkless code sandbox. Trusted typed
capabilities connect commands to real native work. V13 prospectively adds a
pre-review task-routing capability: source can choose a subset of actual native
eligible paper/reviewer tasks, including none, before original review calls.
Existing reviewer eligibility/COI identity semantics and duplicate-task legality
are technical native contracts, disclosed separately from the objective. No
invented review charge or minimum review quota is added. The default original
world remains equivalent when the opt-in capability is absent.

Prospective plan events retain the complete original plan payload and upstream
source-port/event lineage so an auditor can reconstruct the actually applied
plan without executing source again. Historical missing provenance is not
retroactively fabricated.
