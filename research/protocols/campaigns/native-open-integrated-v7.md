# Integrated open-native engineering pilot v7

Preregistered before any v7 live inference. No historical raw/source is changed.
Purpose: exercise combined open domain, process, mixed design generation and
represented backward interfaces on the original fixed-Qwen researcher world.
Not a scaled scientific experiment or a test of beneficial science policy.

- One development seed42, five original researcher agents, one conference,
  two native years and four-year original corpus. No held-out inference.
- Two external authoring generations; each authors a full evolving vocabulary
  and draws two conditional IID executable designs. Four worlds maximum.
- External Codex specialist authorship is self-reported; the fixed local
  Qwen3:8B is the researcher model, NOT the institutional author in this probe.
  No paid model API. Missing source is a durable hash-bound inbox wait.
- Minimize `-native.accepted_decisions - 0.1 *
  native.institutional_context_deliveries`. This deliberately simple count loss
  is gameable and does not define scientific value. No undeclared merit veto.
- Starting developer composition uses data-defined cooperative participants,
  scientific records, actual researcher input/project actions, bounded repeated
  sandbox activities, explicit dependency edges and two recurrent tensor nodes.
  The author may change code, algorithms, parameters and graph/process structure
  subject to explicit technical contracts. Keep the instrumented tensor IDs/
  output and original scientific phases so their backward can be compared.
- Hybrid campaign updates conditional discrete/continuous likelihood weights
  and the external designer-strategy mixture using actual losses. New generation
  receives complete saved history; no finite fixed institution catalogue.
- Every world records real HTTP/code inputs, original checkpoints, domain/action
  receipts, actual process events, native losses and represented backward. No
  derivative of generated text/Python/native reactions is fabricated.
- Numeric conditional backward passes/failures are reported independently of
  native performance. Broader G2 finite-radius/native-fidelity experiments are
  separately labelled original-world scripted QA, not these live results.
- Technical failures retain null costs and raw bytes. They do not trigger hidden
  retries, replacement designs or numeric penalties. Cold reopening binds exact
  source/model/corpus/seeds/design/request/response bytes. Up to four designs,
  not a success-conditioned sample count. Unexpected blockers require a separate
  amendment, not rewriting this record.

Runner: `scripts/run_native_open_pilot_v7.py`. Execution uses a clean pinned
experiment worktree, fixed `PYTHONHASHSEED=42`, CPU retrieval and the existing
shared inference lock. Ordinary source/model format errors are outcomes, not
grounds to claim a successful experiment. Evidence and UI export must preserve
all observed failure/null states and identify this probe as engineering-only.
