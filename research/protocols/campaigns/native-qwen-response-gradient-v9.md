# V9: actual-Qwen response-aware institutional update

This protocol is fixed before any new Qwen response. The original two-year,
five-author, seed42 native researcher world and four-year real corpus remain.
It is a bounded development/implementation study, not population/seed scale-up,
held-out generalization, automatic invention or scientific-value validation.
Fixed Qwen3:8B weights/digest, 768-token non-thinking replies, CPU RAG and the
existing serialized local inference lock are retained. No paid provider is used.

## Fixed objective, actual freedom, and support

Use the existing unmodified `native-joint-v5-net-reviewed-utility` LossSpec:
minimize `3.25*A-Q+0.05*R`. No fairness, participation, novelty or promotion veto
is added. All-reject remains legal. Technical failure has null loss.

The developer-authored graph extends the original world with a real review
charter and the existing tensor selection implementation. The one optimized
institution coordinate is a rubric's evidence weight in [0,1], complemented by
originality weight 1-weight. It changes information in actual reviewer inputs,
not LLM weights or target scores. The original integer parser is preserved.
Year1 sends no charter message for any design. Only after Year2
research/submission/costs, phase110/115 before original review120, does the
variable charter reach actual reviewers. An opt-in public-payload renderer shows
only the canonical payload, never message IDs, source IDs or lineage hashes;
these remain out-of-band in actual receipts. No earlier researcher sees the variable
coordinate. Later native publication/funding still run. This is one local
parameter experiment in the existing broader structural design system, not a
claim to differentiate every possible institution or the world's text/ontology.

Existing addressed selection uses fixed thresholds3.25, bias0, memory cost0.01.
Its routing and recurrent memory remain. A second tensor institution accounts
for the SAME native utility loss from actual actions/scores/review counts.
Hard replay must reproduce the actual loss; mismatch is exposed, not fitted away.

## Fixed maximum budget and sequence

Six fresh worlds maximum, no success-conditioned replacements:

1. Calibration weights0.2,0.5,0.8 in that order.
2. Fit a local raw response operator only on those three endpoints. Candidate
   temperatures [1,0.2,0.05,0.01] selected by calibration loss RMSE, ties declared
   order. Per-review raw scores are parsed individually then averaged per actual
   paper; heterogeneous rows need exact prospective task/record identity proof.
3. Compute center0.5 point backpropagation and candidate BEFORE unused endpoints
   are read. Proposed weight =0.5 -0.02*gradient, with displacement clipped to
   [-0.10,0.10] and weight clipped to calibration support[0.2,0.8], avoiding both
   unused endpoints. No additional quantization is added. A zero gradient
   causes an explicit unchanged candidate, not an invented gradient or reroll.
4. Freeze and save the operator/proposal. Run unused weights0.35 and0.65, then
   the one precomputed candidate. Even an unchanged candidate is one physical
   reevaluation; it is not claimed independent deterministic improvement.

Every world has fresh physical responses in its own durable cache. A failure
stops the batch and is retained. Missing identity/support/changed paper or review
shape is explicit unsupported, never padded, averaged before integer parsing,
zero-imputed or silently relabelled. A prospective implementation amendment may
fix a genuine ordinary bug, but must retain the original attempt and explicitly
account for all additional forward worlds/replies. No semantic retry after a
poor valid native outcome. A separate scripted original-world integration QA
is developer verification only and never counted as actual-Qwen evidence.

## Auditable checks, not merit constraints

Freeze clean source before native runs; use a separate immutable experiment
worktree and preserve v8 raw/source/protocols. Bind full initial physical state,
corpus/model/source/seed/design, exact wire↔SQL payload SHA bijection and original
derived review task seed/index/attempt to semantic paper/conference/reviewer
identities. Across endpoints verify actual initial state, all pre-intervention
request/reply sequences and pre-intervention scientific observation are identical;
model-visible Year2 review prompts may differ only in the two declared complementary
rubric weights. Unrelated pre-intervention drift is explicitly unsupported for
this controlled local response fit. Capture owner-asserted completion receipts at completion, not later
pretend to authenticate timing. Record all endpoint/checkpoint/wire/SQL/code and
operator hashes, failures and all physical reply counts.

Report point gradient separately from finite path-integral and actual finite
native differences. Compare response-aware vs frozen-response predictions at
the two unused development coordinates, absolute and finite-delta errors,
hard/soft gap, native residual, raw response drift and any identity mismatch.
Fidelity tolerances are diagnostic: endpoint atol0.001/rtol0.0001, integrated
atol0.01/rtol0.001, 128-point quadrature. No fidelity threshold vetoes native loss
or hides an unfavorable candidate. No hyperparameter/candidate retuning using
unused outcomes. These coordinates are unused in fitting, NOT held-out seeds.

The goal completes when the real loop executes with truthful evidence even if
fidelity or improvement fails; ordinary unimplemented links do not count as
research failure. A learned numeric response map's autograd is not an exact
Qwen/text/native-world Jacobian. Favorable review scores are not scientific value.
