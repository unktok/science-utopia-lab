## Motivation and intervention

Alias-aligned examples resolve the observed first-node self-reference. The
model then repeatedly refers to `node:decision_engine:outputs`, which is not a
declared output port, and omits a signal output for the native completion exit.
Generated source independently confuses list inputs/paper lists with mappings.
The goal is a working feedback loop, not merely repeated format failures.

Inspection also identifies a host-side prompt projection defect: the generic
bounded view can replace deep lists with diagnostic dictionaries. Execution
always used untouched native records, but the displayed example container types
could mislead source generation. A3 uses a type-preserving presentation view:
prose/list lengths may be bounded, but lists remain lists at every depth and
real input envelopes remain lists of payload records. Raw inputs are unchanged.
This is recorded as a prompt-interface correction, not attributed solely to
insufficient model capability or claimed as a new institutional algorithm.

Separate authoring into two explicit phases. First generate an arbitrary graph
plan: local nodes/order, free ports/protocol schemas, all source connections and
exports, parameters and memory schema, but NO institutional Python. Mechanical
structural validation may use an explicitly labelled NEVER-EXECUTED placeholder
to check the existing graph compiler; it is never a candidate or world result.
Then generate all actual Python functions against the chosen exact interfaces.
Only after every authored function is present are full chronological native
probes permitted. No host code or connection fills a semantic gap. The complete
generated institution still runs in the original researcher world, not a numeric
surrogate or prerecorded input replay relabeled as a fresh world.

Each adaptive slot has at most3 graph-plan drafts and3 all-node source drafts.
An eligible structural plan has null objective loss; only an actual completed
native trajectory supplies a numerical loss. All exact phase prompts, replies,
repair chains, plan/source identity and container receipts are retained. An
exhausted phase halts the arm; no automatic fresh plan search hides source failure.

Designer reasoning is enabled explicitly for this attempt with an8192-token
cap, using the SAME fixed Qwen3:8b model digest, temperature0.2. This changes
designer inference settings, not researcher weights or researcher thinking/token
settings. The native researcher factory remains unchanged at thinkingFalse and
768 output tokens. This combined workflow change is not a causal ablation of
staging versus reasoning; no isolated efficacy claim will be made.
