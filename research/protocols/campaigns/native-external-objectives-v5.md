## Question and authorization scope

Can the existing code/protocol/graph design interface close a result-conditioned
loop in the ORIGINAL researcher world when the designer is an explicitly
identified Codex specialist rather than the same small local researcher model?
The user has requested LLM-authored executable institutions and parallel Codex
specialists. This uses that existing workflow, not a new paid provider API or
installation. Researcher agents remain fixed local Qwen3:8b. A nonblocking user
preference question about designer identity is still unanswered at registration;
this assumption is explicit and can be overridden. No result from this pilot
will be called a local-Qwen-authored institution or provider-authenticated output.

The author receives each exact hash-bound request and its actual loss/feedback,
then writes a complete manifest response with its own Python, protocol, nodes,
order and every wire/export. The root operator does not insert a policy body,
repair source or fill missing connections. ABI documentation and existing native
consumer semantics may be inspected; copying a host algorithm must not be
reported as de-novo invention. Technical diagnostics are available for at most
three drafts per proposal. A missing response is a resumable waiting state,
not an invalid loss. The specialist can author both arms and is not blinded to
their objectives; this is an engineering demonstration, not a blinded comparison.
