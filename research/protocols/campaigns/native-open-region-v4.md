# Native open region v4: one joint generated institution

Status: frozen implementation/protocol before first v4 model request.

## Question and budget

Can the fixed local Qwen3:8b emit executable institution Python, custom internal
protocols, nodes and wiring that run in the original native researcher world,
rather than only revise source inside a fixed graph?

One candidate, at most three technical drafts, temperature 0.2, effective output
cap 4096 tokens, thinking disabled. Eligible source is never hand-edited. The
first technically eligible candidate receives exactly one fresh two-year native
execution, five independent balanced researchers, development seed 1301, original
four-year corpus. Equal, inactive and worse outcomes remain valid; there are no
quality, activity, fairness or improvement admission floors. If all drafts fail,
record failure without native loss, replacement candidate or reroll.

The explicit engineering LossSpec is inherited unchanged from the frozen v3
baseline: minimize negative actual accepted-decision count. This is a gameable
count objective, not a scientific-quality objective or endorsement of a policy.
The run is capability evidence, not a multi-objective comparison study.

## Authoring and probes

The first live cut replaces `world.selection`, keeping the actual external
review inputs and publication consumers. It allows 1..6 arbitrary Python nodes,
0..32 edges, invented protocol artifact kinds and payload schemas, freely named
ports and persistent JSON state, in the open phase interval (120,160). Edges are
zero-delay and follow increasing internal phases. The current probe does not
support native legacy methods without recorded Python boundaries or arbitrary
cross-year graph surgery. Generic compiler/prober QA also covers a communication
cut that delivers new messages into actual next-year researcher requests.

The v4 compact authoring format embeds `payload_schema` in each port. A
mechanical compiler derives the duplicated input/output schema dictionaries and
the descriptive `custom` family. It does **not** supply, select or rewrite
institution logic. Python, node identities, protocols and edges are preserved.
This directly addresses v3's port/schema disagreement and invalid family tag
failures, rather than expanding the experiment budget.

The prompt contains explicit lossy semantic projections, not lengthy researcher
prose or parent implementation code. All full original contexts, across every
recorded year starting from year one, are used in isolated chronological probes.
Generated memory carries forward between years and resets only between native
runs. Real native paper/conference identity and publication contracts are checked;
isolated outputs are never called loss observations. Fresh native forward runs
remain authoritative and can fail despite successful frozen-input probing.

Exact prompts, generated drafts saved **before** probing, technical errors,
repair-parent hashes, patch/source/runtime/image/context/result hashes and cache
bindings are durable. Resume never silently requests a replacement for a saved
draft. Old v3 drafts are retained unchanged. Independent reopening audits verify
the raw model manifest mechanically recompiles to the actual evaluated graph.

## Interpretation boundaries

A successful rollout establishes an executable model-generated graph region,
not useful open-ended social invention, algorithmic novelty, generalization,
full-world differentiability or recursive self-improvement. A one-node output
is legal and must not be claimed as new internal topology. Report actual node
and protocol counts rather than infer invention from labels. The current cut
and surrounding native consumers remain fixed. Later generic-boundary QA and
live-world migration are separate evidence, not retroactive properties of this
single two-year pilot.
