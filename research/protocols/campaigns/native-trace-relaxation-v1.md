Frozen engineering protocol before live execution, 2026-10-31. Two systems,
seed 1301, TWO native years each, five independent balanced researchers,
original SciEvo data, local Qwen3:8b non-thinking/768 tokens, one worker. This
shortens population/horizon, not researcher activity into numeric world laws.

Initial developer-authored institution: original research/reviews -> isolated
feature extractor -> tensor address/threshold/branch/decision memory -> isolated
consumer committing decisions to native publication. The same tensor program
has hard operational and soft interpretations. Its gates/addresses, not LLM
token generation or arbitrary Python, carry pathwise gradients.

Run initial system completely. Freeze and hash its actual tensor input/output,
identity and state trace; reproduce hard execution. Fit institution keys,
threshold slots and bias for 30 Adam updates, learning rate 0.1, temperature 0.8,
against the explicit conditional negative soft accepted-count objective.
Carry represented memory/edges through autograd; all other native inputs are
observed conditioning data. Do not relabel this conditional objective as an
exact derivative of the counterfactual whole-world LossSpec.

Commit the fitted program into a second SystemSpec and run a fresh native world
under the SAME explicit negative actual accepted-decision LossSpec. Return only
that real world loss to the outer controller. Retain original incumbent if the
proposal is worse. All-accept remains legal, not scientific quality; no extra
fairness/promotion constraints. Improvement is not a technical gate.

Preserve failures/null losses, source/model/corpus fingerprints, source/image
receipts, native traces and fitting history. No hidden reroll, source edit or
retuning after outcomes. Report soft-vs-hard gap and the fresh world outcome
separately. Two-year single-seed execution establishes only integration, not
stable superiority, generality to arbitrary code or full-world differentiability.

## Pre-execution amendment: fixed corpus horizon

The first clean attempt at `228a030` entered two-year corpus embedding
preflight without a matching cached embedding matrix. No native candidate or
model/world observation was executed. It was stopped after roughly six minutes
of preprocessing (SIGINT and SIGTERM did not stop the encoder promptly; exact
task-owned PID was then killed). Partial data/cache/logs are retained; no scored
trajectory is discarded or replaced.

The amended run keeps TWO simulation years and explicitly sets
`--corpus-years 4`: the original four-year corpus and its already verified
embedding cache are held fixed across both systems. Per-year native retrieval
eligibility remains enforced; future documents are not made available early.
The separate corpus horizon is included in source/checkpoint/cache bindings.
This avoids recomputing document embeddings every time a short experiment
changes duration. A new clean source worktree is used, not an edit to the old
attempt. Compare this probe only within its declared fixed-corpus contract.
