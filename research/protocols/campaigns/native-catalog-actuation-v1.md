# Native catalog planning actuation comparison

Compare developer planning controls in the original five-founder four-year
world to distinguish institutional advice from actual project assignment.
This follows the closed capacity T/P pilot; it does not reopen its search.

## Common world and outcomes

Reuse development seed61001 explicitly. Keep original Qwen3-8B researcher
weights, corpus, all native activities, two-output project cap, initial30

Use the literal reviewed-all reserve-proximity allocation parent in all arms.

## Common agenda and three conditions

At phase1 of each year, isolated developer code reads the same opening snapshot
and exact original catalog. For each active author whose previous project ends
strictly before this year, choose the shortest topic in their displayed
expertise, breaking ties by literal topic string. Preserve the full catalog
record, including its actual duration. Set start to this year and end to
start plus duration minus one. Preserve ongoing projects. The rule is hand
written, not generated institutional invention or an optimality claim.

Execute cut, information and project once each in that fixed order. All have
the same code, catalog, graph, schedule and granted action authority; only the
explicit actuation parameter differs. Cut emits the agenda without an effect.
Information delivers the same assignment as native context to each actual
researcher, leaving original project choice active. Project applies the legal
assignment through `native.catalog-project.v1` at phase2, before original
phase10 planning. The latter replaces a choice, not the native production law.
The new fixed-production catalog-planning scope preserves old scopes and
forbids arbitrary duration edits, ongoing-project overwrite and raw
`native.project` grants. Its validator permits any displayed catalog topic;
it does not impose the developer shortest-project rule on future designs.

The initial agendas must match across the freshly run arms. Later agendas may
diverge because native state differs. Advice obedience and direct assignment
are distinct treatments. Record original scientist inputs, actual projects,
production, accepted records, resource histories and costs, including skipped
planning calls. Do not interpret a skipped choice as LLM compliance.

## Interpretation and next decision

Compare every arm and both losses, not only the best outcome. Trace whether
the intervention actually changes projects and whether native production
consumes them. A useful actuation effect motivates a separately frozen free
objective-conditioned search with strong same-authority planning controls.
A flat or adverse result instead motivates analysis of the consumed state
and native production support. The developer comparison itself cannot show
automatic invention, optimizer superiority or general scientific benefit.
