# V15 staged local-LLM authoring and original-world feedback

Prospective first revision, written before any v15 generation/native call.
The user explicitly authorizes parallel work and continuing engineering until
the automatic authored-institution/native-feedback loop actually works.
That authorizes further separately declared revisions, not erasing failures or
silently extending a fixed campaign after observing its outcome.

## Fixed first pilot

Two own-history-separated objectives: existing throughput `L=-A` and existing
reviewed-production `L=-Q+0.5R`. Each gets two blackbox generations/one native
slot per generation: four scheduled native slots total. Original five authors,
two years, seed42, real four-year corpus and fixed local Qwen3:8B researcher
weights stay unchanged. The disclosed existing `open_native_system` is the
initial seed. Developer seed code is never attributed to the new designer.

The designer is the pinned local Qwen, with no human/Codex candidate code.
Each generation has at most16 tool/model steps and2048 output tokens per call:
maximum64 generation POSTs across four generations, with up to64 designer
digest-preflight GETs counted separately. Binding construction and each native
factory additionally read model metadata through GET `/api/tags`; restarting
the CLI can repeat these metadata reads, not generation POSTs. There are no
designer transport retries. Inspection, invalid edits,
technical repairs and interrupted dispatch intents all consume steps.
An intent without a completed receipt remains response/cost unknown and is not
redispatched. Explicit valid finish is required; no automatic identity fallback.

## Unrestricted staged authoring

The designer sees the exact loss, all its own scalar outcomes/failures and a
compact full node index, not a hand-authored catalogue of institution policies.
It can inspect exact subtrees, make literal atomic JSON edits or string splices,
configure arbitrary declared design factors/continuous coordinates, validate,
and finish. Nodes, Python algorithms, protocols, ports, wires, schedules and
processes remain mutable. Large source can be built in chunks without host
completion/repair. Full exact requests, raw model outputs, tool actions/results,
draft hashes, protocol/source identities and omissions are archived.

Intermediate drafts may have incomplete graph connections while construction
continues. Final compilation uses the existing complete SystemSpec/source/ABI/
image/distribution checks. Generated code never runs on the host; actual code
execution uses the pinned existing no-network Docker executor. Static author
validation adds no native probe. No scientific-value, quality, fairness,
novelty, improvement or adoption veto is introduced. Explicit retention is legal.

## Execution, evidence and stopping

Freeze all requests, source, provider/model/corpus/image and budgets before the
first generation. The explicitly authorized CLI uses the same durable staged
queue/controller as the opt-in UI. CLI consent is not called browser consent.
Each usable generated institution is evaluated in the original world; actual
loss and all own history reach the next generation. Failed generation slots
remain null, never replacement baselines or invented numeric penalties.
Native failures retain their actual response/checkpoint/source evidence.

This revision stops after its fixed budget irrespective of success. If a
technical obstacle prevents the user's end-to-end goal, preserve this revision,
diagnose it and declare a new source/budget before further calls. Do not pool
successful-only paths or label engineering revisions a controlled comparison.
The operational goal is both generations in at least one arm reaching actual
native evaluation with no manual candidate implementation; useful invention,
loss improvement and whole-world differentiation are not completion gates.

Independent read-only audit must join raw action→exact draft/source/graph→
compiled definition→actual native source/effects/checkpoints→remeasured loss,
and prove the next prompt used only its own earlier outcomes. Separate designer
and scientist calls/costs, unknown interruptions, all failures/ties and source
pins remain explicit. UI observations and schematic city animation are not
independent scientific evidence. No held-out study or scale-up is claimed.
