# Native feedback breadth v2 — working execution paths, negative discovery result

2026-11-01. Development integration, not held-out evidence or a policy claim.
Protocol: [native-feedback-breadth-v2](../protocols/campaigns/native-feedback-breadth-v2.md).
Implementation and reproduction: [component/runbook](../components/native-feedback-and-interactive-design-v2.md).

## Outcome against the original goals

The actual original researcher world, not the numeric miniature, now supports:

1. Native execution → observed loss/history/activity → local-LLM source revision
   → isolated execution → fresh native evaluation, with every attempt retained.
2. An antithetic gradient estimator of a design distribution, evaluated using
   complete fresh native rollouts including subsequent fixed-LLM responses.
3. Browser-edited SystemSpec and LossSpec → explicit compute consent → durable
   local job → pinned native worker → actual result loaded into the same UI.

These are execution capabilities, not successful useful institutional invention,
full-world pathwise differentiation, or a complete science-management game.
No fairness, minimum-message-count, or promotion veto was added to the loss.

## Actual small native runs

All use fixed Qwen3:8b, five independent balanced researchers, development
seed1301, and the original four-year cached corpus. Researchers retain their
weights/personas; new responses are generated in each fresh simulation.
The minimized engineering loss is negative accepted-decision count. It is
explicitly gameable and does not measure scientific quality.

### Source revision: the mechanism works, the proposed algorithm does not improve

The designer receives exact prior observations, actual checkpoint-derived author
state, node execution/delivery counts and (from the amendment) bounded real paper
histories. Generated source is preserved exactly, not repaired by a developer.
The controller freezes the loss and lineage and evaluates technically valid
source even when it emits nothing. There are 168, 168 and 190 saved researcher
responses respectively across the three source probes, with no model retry or
failure recorded in their completed native executions.

All five executed revisions emitted the same source bytes, digest
`950e60beac74095687d25c554d48a009a0e2486b94e8b06f4bc261a8ca324a74`
(canonical JSON-string digest). Their condition remained `count > 3`; it never
activated in these worlds. Several rationales described a substantive change
which the source did not implement. Rationale is untrusted model text, not
evidence of an algorithm change or scientific benefit.

The final, separately declared diagnosis-before-code probe initially generated
a different accepted-paper algorithm but read a nonexistent top-level
`paper['decision']`. The isolated probe recorded `KeyError: 'decision'` before
native evaluation; the actual decisions are nested in review history. One
model-generated technical repair reverted to the inert counting algorithm.
Both draft and plan receipts are retained. Its three-year horizon was declared
before launch to allow year2 papers → advice → year3 researcher activity; it
was not an unreported reroll for a favorable outcome.

This establishes a result-conditioned executable revision loop, **not** useful
source invention, model-invented attachment topology, or successful source
optimization. The source-only proposer currently fixes an existing
observation/messages node's ports and attachment. General atomic graph/source
patching is a separate available interface; that does not make this particular
source-only experiment an unconstrained topology search.

### Gradient: actual input pathway, zero observed estimator

A declared developer-authored advisory institution sends its exploration-weight
coordinate to real researchers; it does not directly change acceptance rules.
One antithetic pair uses search seed42, sigma0.7 and learning rate0.1. Both draws
deliver ten messages, and six actual second-year HTTP requests in each world
contain the institutional context. Raw payload hashes match the completed
response journals. Thus this cost path is not frozen-input trace fitting.

Both native losses are -1; the paired estimator is exactly `[0]` and the design
distribution mean stays `[0]`. We did not reroll until it became nonzero.
This neither proves a zero true derivative nor shows a performance benefit.
The derivative is of the Gaussian-smoothed design distribution in latent
coordinates; there is no backpropagation through LLM tokens or the entire
native world. Prior conditional hard/soft tensor autograd remains a different
method and evidence boundary.

### UI: an actual round trip, not a screenshot of fabricated execution

The browser edited the native tensor selection bias to -2, validated the exact
JSON request, checked explicit compute consent, and queued
`job-d778b4d49f7e4cac8e9ddf53471ecd31`. A separate source-pinned worker executed
two native years and saved 56 researcher responses. The completed -3 loss was
independently recomputed from its checkpoints and the **exact submitted**
LossSpec, then the checksum-bound result loaded in the same browser with five
actual researchers. No new baseline or optimizer superiority is inferred.

The queue resumes interrupted running jobs before claiming new work; failures
remain null-score technical failures. Records are immutable: editing submits a
new simulation, not a hot mutation/migration of the viewed society. UI copy is
English. Desktop and390px mobile browser QA recorded no runtime exception or
horizontal overflow. The code/graph JSON editor is functional, not a finished
visual graph editor or management-game economy.

## Remaining non-scale gates

1. Generate a genuinely changed useful algorithm/protocol and demonstrate its
   actual researcher-input effect; generalize source revision beyond this
   host-attached observation/messages interface, and connect joint producer/
   consumer/topology invention to the same real-feedback loop.
2. Extend faithful differentiable representations and test their fidelity
   against fresh native outcomes. Full-world input-response autograd remains
   unimplemented; a full-rollout score estimator does not close that gap.
3. Broaden actual native role/artifact consumers and schedules without turning
   them into a fixed catalog or silently changing scientific world laws.
4. Visual graph authoring, richer play feedback, same-society state migration,
   internal designer feedback and recursive redesign of the designer remain.
5. General science-quality constructs and objective-conditioned source/graph
   search studies remain; accepted-count plumbing is not that research result.
