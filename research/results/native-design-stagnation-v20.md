All23 actual V19 designer POSTs contain both SYSTEM permission to invent
arbitrary literal Python and new institutions, and a source-owned USER task
saying "do not invent a candidate or a measured outcome". The turn task
incorrectly conflates proposing an institution with fabricating a measurement.
This is an instruction-design defect. Its presence does not establish that it
alone caused all parent retentions or that its removal will solve exploration.

The repair permits new candidate code and institutions, while prohibiting
fabricated measurements and claims that an unexecuted candidate was evaluated.

interpreter, compiler, ABI, model, losses and scientific setting stay unchanged.

introduced, and no candidate policy is supplied by the host.
