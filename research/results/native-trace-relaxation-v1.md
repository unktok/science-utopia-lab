## Exact scope

communication and tensor memory. The separate deterministic native integration
tests include TWO tensor institution nodes with nonzero cross-node gradients
and six-year completed-checkpoint resume. Actual live probe has one tensor
institution with two native years, not a differentiated natural-language swarm.

text construction, arbitrary generated Python and subsequent researcher/world
feedback do not yet carry pathwise input derivatives. The current method is
not the old Gaussian score-function estimator, not full native autograd, and
not proof of a faithful differentiable representation of every institution.
