## What completed

A clean `1b2cbcbb21568d04e92c91434023fb735183116e` worktree ran the actual
original Simulation for four years with five Qwen3-8B researchers in five
institutions (one balanced researcher each), seed 1301. Original corpus/
retrieval, language-based research/project decisions, submissions, citations,
reviews, publication, funding and longitudinal histories were retained. The
original four-year SciEvo corpus contained 103,107 papers. No fixture phase or
substitute numeric researcher world was used in this live run.

The native graph also ran a programmer-authored Python research-commons node
in a pinned no-network Docker container. It read actual projects/papers and
delivered optional replication/robustness information to researchers. This is
an institution integration example, not an LLM-invented or optimized system.

## What deterministic QA establishes separately

The focused suite passed 611 tests, with three skips, in 53.40 seconds.
Skips were two opt-in real-ledger/tokenizer checks and optional rapidgzip;
Docker source-execution tests ran. This is not a full-repository suite.

- Six-year baseline graph/original coordinator scientific state, RNG and
  wire-input equivalence with identical scripted replies/corpus and clock.
- New typed protocol delivery to real subsequent researcher inputs;
  disconnection and delayed-edge controls change its availability.
- Isolated-source selection replacement, including removal of native peer
  review, changes real publication/history and subsequent researcher context.
- New LLM institution state persists; actor codecs preserve a new actor class.
- A new non-paper artifact type has identity/content/update history in native
  storage and canonical replay; cross-store identity collisions fail.
- Completed-year restore preserves context, queues, graph state and events.
- Native Suggestion/LossSpec/Observation evaluation verifies seed/spec binding
  and keeps technical failure separate from numerical loss.

These QA capabilities were not all exercised by the one live example. In
particular, its institution source was hand-written and its peer review was
not removed; the new generic artifact-declaration option was not used there.

## Failures retained, not hidden

Four earlier clean attempts failed before this completion. Multi-year projects
exposed a missing empty-year tracker bucket and a columnless empty paper table;
the first publication after an empty year exposed an empty-citation assertion.
Those implementation fixes preserve empty histories without inventing papers,
citations or changing research duration. The initial all-in-one-institution
configuration also excluded every reviewer through original conflicts of
interest. Rather than fabricate reviews or change selection, the amended probe
uses five independent institutions and balanced strategies. This population
change means it is not a paired comparison with the earlier failures.

All failures, caches, source commits and amendments remain recorded. No failed
probe received a fabricated loss. Their elapsed times are listed separately;
532.27 seconds is not total development/debugging time. Non-thinking and the
768-token cap also differ from historical campaigns, so this probe does not
establish a campaign speedup or an optimization-runtime estimate.

## What remains

The original world is a minimum instance, not the final ontology. Arbitrary
multi-node source/protocol synthesis and durable native source optimization
are not complete. Research/submission/funding still share native annual domain
prerequisites; codecs and artifact stores do not automatically supply new actor
behavior or scientific activities. New hypotheses, experiments, software,
datasets and correction workflows need actual producer/consumer effects, not
only names and records. Native-world differentiation remains unimplemented:
the next gradient track must bind estimators and validation to these native
trajectories, not optimize a simpler replacement world. No game implementation
or manuscript PDF changed in this integration track.
