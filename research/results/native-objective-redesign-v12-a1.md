# Objective-conditioned open native redesign v12: actual result

All six scheduled original-native worlds complete: **565 fresh physical Qwen
responses, zero response reuse and no world-level technical failure**. The
throughput path is `[-10, -10, -10]`; utility is `[-1/6, 0, -1/6]`. Both arms
retain their first observed best. The new utility milestone-clinic mechanism
really changes native project timelines and researcher inputs, but the complete
G1 revision containing it does not improve its bound objective in this pilot.

The [independent audit](native-objective-redesign-v12-a1.json) replays request,
own-history, manifest, candidate, parent and update lineage; reextracts losses
from actual native checkpoints; verifies physical source/context/result and
response receipts; and retains every current system and exact best tie. Two
audits are byte-identical, with all107 raw files unchanged. No model, container,
generated institutional source or new native world is executed by the auditor.

acceptance rule is part of the forward institution, not an external veto on

## Actual native activity effects, not merely attached source

The throughput annual scheduler produces ten accepted native research-plan
amendments per world, five per year. All ten match their recorded generated
outputs and the later annual author timeline/direction snapshots. These are
`native.system.research_plan_applied` effects, distinct from the domain
`native.project` command counter, which is zero here.

In utility G1, the clinic source executes in both years but emits only **two
actual amendments, both in year1**. It changes these original author projects:

| Actual author | Original end year in recorded code input/result | Amended end year | Duration | Year1 submission |
|---|---:|---:|---:|---|
| `institution_0003_researcher_0` | 3 | 2 | 2 years | false |
| `institution_0004_researcher_0` | 1 | 2 | 2 years | false |

The year1 native effect's submitter list is empty, and both annual author
snapshots match the committed amendments. In year2 all five original authors
are listed as submitters; no additional clinic amendment is emitted. The
source thus shortens one project and extends another: it is not simply a rule
accelerating every researcher or a fabricated publication bonus. Its output
is bound to exact code/source/image/context/result and native event hashes.

## Cost, provenance and limits

Measured native `llm_call_stats.elapsed_seconds` sums to **2166.5264 seconds
(36.11 minutes)**: throughput1323.2926 seconds and utility843.2338 seconds.
This is time inside recorded model calls, not total campaign wall time, which
also includes sandbox calls, authoring, guards, checkpoints and orchestration.
The separately budgeted two-world final-control followup is not included here.

This finite probe demonstrates freely authored, objective-conditioned native
institutions; source/topology/process revision and legal retention under actual
loss feedback; and a substantive but unsuccessful new activity mechanism.
It does not establish held-out improvement, optimizer superiority, causal
science-policy benefit, scientific value, authenticated LLM invention or
recursive designer improvement. One development world seed, one draw per
generation and repeated fixed designs do not become independent population/seed
replications. No initial unevaluated parent is assigned an invented baseline loss.
