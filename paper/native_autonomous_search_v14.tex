\section{Automatic Institutional Search from an Objective and Budget}
\label{sec:automatic-search-v14}

The preceding pilot connects free design and conditional optimization but uses
externally supplied code responses. We next remove that manual authoring
step. An exact LossSpec, initial SystemSpec, method and native-evaluation
budget drive a durable controller: request a model-authored institution,
validate its literal edits, evaluate it in the original researcher world,
and feed the resulting own history to the next authoring request.
This is automation of institutional search, not training the researcher LLM.

\paragraph{Authored algorithms and structure.}
The local fixed Qwen3:8B designer emits an atomic JSON-pointer transaction,
optional conditional edit factors and bounded continuous coordinates, plus
a rationale. The transaction can change Python bodies, mechanisms, typed
ports, protocol types, connections, schedules and process metadata. It is
not a choice among a host-written institution catalogue. The compiler adds
only the exact parent fingerprint and provenance envelopes; it does not
repair Python, fill missing wires or invent missing scientific measurements.
Every reachable authored code node must retain the operator-pinned sandbox
image. Existing no-network Docker execution remains separate from the host.
The initial system is the disclosed pre-existing open-world seed example;
its developer-written source is not attributed to this new model author.

The prompt contains the complete current parent, exact loss and a deterministic
own-history view with every scalar outcome, null failure and saved update.
Repeated older candidate bodies are represented by hashes in this view;
the complete requests and histories remain archived. Thus the author has
recorded feedback, without a claim that every historical byte is in its
context window. Only its own run's history is supplied. Raw model text,
strictly parsed output, technical diagnostics and compiled definitions are
linked to the exact request and source. Code is never executed on the host.

\paragraph{One interface, two existing search routes.}
Black-box mode requests one free institution per scheduled slot, runs one
native forward and supplies the complete own feedback to the next generation.
Nested-LR mode reuses the preceding four-slot schedule unchanged: two IID
G0 designs, one LOO score update, one exact updated-G0 forward, and one
own-history free G1 redesign/forward. The UI/API supports black-box budgets
from one to eight and nested-LR exactly four, rather than claiming arbitrary
nested schedules. An explicitly empty parameter set and explicit retention
remain legal. There is no implicit transport between changed coordinate
meanings and no whole-world or source-generator derivative requirement.

\paragraph{Budgets, failures and restart.}
The prospective pilot fixes eight native slots and six free authoring requests
(Table~\ref{tab:automatic-budget-v14}). Each authoring request permits at most
two technical attempts, each with at most 4096 output tokens: at most twelve
generation POSTs, with model-digest verification GETs counted separately.
There are no network/SDK retries. A durable dispatch intent precedes each call;
an interrupted intent without a completed receipt consumes that attempt,
without redispatch or an exactly-once HTTP claim. Successful response receipts
are replayed rather than regenerated. Technical exhaustion produces an invalid
vocabulary and charged null slots, never a substituted baseline. A later
scheduled generation may use the failure as feedback, but receives no extra
budget. Native checkpoint/response replay supports cold restart. All ties,
worse draws and failed designs remain in the trace.

\paragraph{Local consent and observed progress.}
The same controller backs a loopback-only authenticated queue. A user edits
the existing English Foundry workbench, validates the exact request and grants
fresh request-bound compute consent before enqueueing. Changing the request
invalidates validation and consent; viewing/importing evidence does not
execute or adopt it. Source, model, corpus/dataset and sandbox image are
operator-bound, not request-selected paths, modules or remote endpoints.
Single-writer ownership and a shared inference lock serialize designer and
researcher use of the resident model. Read-only live file observations expose
generation receipts, native checkpoint years and known cache rows. They are
labelled provisional, leave unavailable counts null and cannot establish
completion. Final costs and outcomes come from independent stopped-writer
audits, separately for the designer and the researcher roles.

The first actual pilot calls this controller from the source-pinned CLI; UI queue,
consent and interruption checks use explicitly SCRIPTED tests rather than an
extra unbudgeted native world. Original-world execution, institutional
authorship and interface verification are reported as distinct evidence.

\paragraph{Closed automatic-authoring pilot.}
All eight scheduled slots terminate at their preregistered budget, but no
institution compiles and no researcher world runs
(Figure~\ref{fig:automatic-search-v14}). Six generation requests receive twelve
actual local-Qwen responses. Nine parsed drafts fail their first edit at
\texttt{/mechanisms/17/parameters/code\_artifact/source}. Element 17 exists but
is the domain-command mechanism, not the Python selection mechanism at
element 7; its parameters have no code artifact. The other three replies reach
the 4096-token limit and are retained as truncated generation failures.
Later operations in rejected transactions are not counted as executed errors.
All native losses are null, not zero. The nested update is unavailable,
not a measured zero gradient. Process exit 0 denotes terminal accounting only.

The nine parsed drafts contain 19 Python-body occurrences and three distinct
bodies. Each is its corresponding seed body with only the final newline
removed; their parsed ASTs are identical. Repeated tensor-node lists also
match the seed. Different source hashes therefore do not establish a new
algorithm. No valid source or topology delta, native effect, scientific
feedback or best institution is available. These observations describe the
attempts; novelty is not an extra admission condition.

Recorded author-adapter time sums to 938.57 s (15.64 min), with 114,252 prompt
and 28,651 completion tokens. All twelve dispatches have known replies;
scientist requests, replies, physical world directories and generated-source
execution receipts are zero. These call intervals are not overall wall time.
Two stopped-writer audits agree byte-for-byte, preserve 54 raw files and match
233 replay-critical source blobs to the actual commit. This is a failed
automatic-authoring integration attempt, not a controlled comparison between
the objectives or optimization methods.

\paragraph{Separate stable-ID authoring interface verification.}
The closed pilot motivates an engineering change, not reinterpretation of
its outputs. An optional authoring IR selects an exact mechanism ID with a
local JSON pointer, or uses an unrestricted full-document pointer for new
nodes, protocols, wires and process metadata. A deterministic compiler
translates explicit addresses after preceding edits; it does not infer or
repair literal values. Missing/ambiguous IDs, nonnumeric coordinates,
schema strings and branch-dependent pointer mappings fail with structured
owner/path/type diagnostics. Full current parent data and a typed path
catalogue are supplied. Unlike a1's cross-generation prompt, the new view
also carries detailed prior generation failures; omitted repeated operands
are explicitly represented by type, size and hash. The immutable journal
binds protocol identity, raw IR, exact translated edits and compiler trace.
The legacy direct authoring protocol remains replayable from its frozen source.

A separately prospective technical QA fixes one throughput black-box request,
two native slots and at most four new generation POSTs. It uses the same
five researchers, two years, seed 42, corpus and fixed local Qwen. The actual
existing workbench validates the request, obtains fresh consent, submits once
and hands it to a separately launched worker. Exact editor numeric tokens
are retained on the wire: parsing and reserializing \texttt{1.0} as
\texttt{1} would change the Python-canonical LossSpec identity. Source, request,
operator identities and budget are frozen before dispatch. Outcomes are
reported separately; source, prompt and format changes are simultaneous and
conditioned on the earlier failure, not a controlled author-model comparison.

\paragraph{Closed interface-QA outcome.}
One real browser validation and one consented submission bind the frozen
request to the actual queue. Its two scheduled generations terminate with
null losses, four dispatch intents, three known responses and one interrupted
response of unknown server processing/cost
(Figure~\ref{fig:authoring-ir-qa-v14}). G0's first draft truncates at 4096 tokens.
An operator launch-PATH omission is detected before any native world; the
owned worker is stopped, its in-flight second intent consumed, and the same
queue resumes with Docker available. The request is not resubmitted and its
budget is not reset. G1's first draft incorrectly supplies a full pointer
with a local selector, yielding a duplicate path prefix. Its second passes
four literal edits but fails the fifth at a nonexistent numeric field.
Neither transaction is repaired, and no candidate compiles or native world
executes. A terminal cold resume returns no job without constructing providers.

Three known replies record 55,749 prompt tokens, 6,994 completion tokens and
332.00 author-adapter seconds; these are partial known costs, not a complete
total or wall time. The unknown attempt is not imputed. No scientist reply,
code execution or checkpoint occurs. Two independent audits agree byte-for-byte,
preserve 26 raw files and match 292 source blobs to this QA's own pin. Authoritative
browser wire text is reparsed in Python to avoid JavaScript integer rounding.
Saved-progress desktop/mobile captures are explicitly not independent audits;
their read-only verifier makes no second submission or model call.

The executable controller, consent, bounded error-feedback and interruption
path are therefore verified, including an actual failing local-model path.
In these frozen v14 studies, automatic local-Qwen authorship reaching
original-world evaluation remains unachieved; the later staged continuation
is reported separately in Section~\ref{sec:staged-authoring-v15}.
This is a concrete authoring-reliability limitation, not a reason
to require scientific benefit or optimizer superiority for platform completion.
The byte guard on prompts is not a provider-tokenizer/context guarantee.
Its fixed budget is not extended to obtain a successful example.
