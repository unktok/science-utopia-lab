\section{Staged Institutional Authoring and Open Researcher Work}
\label{sec:staged-authoring-v15}

The failed one-shot authoring studies motivate an interface change, not a
restriction of the scientific system to a simpler numeric world. A local
fixed-weight Qwen designer can now inspect the exact current institution,
make small literal edits, observe technical diagnostics and continue within
a declared tool budget. The unchanged original researcher world supplies
the loss only after a valid explicit finish. No human author supplies a
replacement candidate in this loop.

\paragraph{Free construction with inspectable intermediate state.}
Six general tools operate on the current JSON design: \texttt{inspect},
\texttt{edit}, \texttt{splice}, \texttt{configure}, \texttt{validate} and
\texttt{finish}. Exact stable-ID selectors or full-document pointers can
address existing structures; full-document edits add arbitrary new mechanisms,
protocols, wires, schedules and process definitions. String splicing builds
literal Python in bounded pieces without a host-written code completion.
Conditional discrete factors and continuous coordinates remain optional.
This is an authoring interface, not an institution-policy catalogue.

An incomplete intermediate graph is allowed while the designer constructs
its connections. A bad pointer rejects its entire edit transaction; static
diagnostics report the actual owner and missing segment. An explicit finish
uses the existing complete graph/source/ABI/image/distribution checks and
does not run a native probe. The host neither repairs source nor silently
finishes a valid draft. Explicit retention is legal; there is no novelty,
scientific-value, quality, fairness or adoption admission test.

The full original design and request are archived. The prompt includes the
complete current node index, exact loss and every own scalar outcome/failure,
while literal source and other bodies are read through inspect. Older tool
addresses and scalar operands are summarized with body type/length/hash
descriptors; the latest complete result is present. These omissions are
explicit rather than an assertion that every archived byte fits in context.
Raw assistant bytes, parsed actions, dispatch intents, tool results, draft
hashes and exact compiled definitions are linked by a durable journal.
Read-only replay reconstructs these transitions without executing generated
source on the host or constructing a model provider.

Subsequent interface-only work separates the fixed authoring protocol into
the trusted system role and adds a read-only effect-ABI namespace to inspect.
Its index derives 34 registered native implementations and one conditional
Python implementation from the actual registry. Five detailed contract cards
cover open researcher work, transfers, domain commands, process dispatch and
Python; other identifiers and plugin omissions are explicit. Shape checks,
semantic constraints, permissions, per-invocation cost bounds and validator
source hashes are exposed without adding a node, task or wire. These later
interfaces are SCRIPTED-tested, not retrospectively attributed to a1 or a2.

\paragraph{New work, addressed to existing researchers.}
The world also gains a general effect capability,
\texttt{native.researcher.work.v15}. An institution supplies an actual author
identity, its own task instruction, arbitrary JSON scientific content,
available artifact references and an object response schema. The recipient
uses the original persona, memory, project, resources and institutional
context, with the same fixed researcher model and response cache. There is
no built-in enumeration of hypothesis, experiment or review activities.

Responses are ordinary typed graph messages. Arbitrary sandboxed consumers
can combine them or connect them to existing explicit project, context,
artifact and resource effects. Merely returning model text does not mint a
paper, resource balance or review score. A declared per-invocation request
cap, batch preflight and process iteration identities make physical work
accountable. Source/task/actor/artifact/prompt/response receipts and cold
restore checks preserve causality. Original phases are unchanged when the
opt-in capability is absent. Its implementation is broader than its actual
use: a runtime feature or SCRIPTED test is not evidence that an automatic
designer discovered or used it in an actual campaign.

\paragraph{Actual first revision: a repeated-read failure.}
The prospective a1 fixes two own-history-separated black-box objectives,
$L_A=-A$ and $L_E=-Q+0.5R$, each with two generations/native slots. Every
generation permits 16 model/tool steps and 2048 output tokens/call, for at
most 64 designer POSTs. Five original researchers, two years, seed 42, the
real four-year corpus and fixed Qwen weights remain unchanged. Model-tag
GETs are separate from generation POSTs. A dispatch without a completed
receipt consumes a step; no transport retry or replacement native budget
is introduced.

At immutable source \texttt{f969f7c}, all four generations exhaust their
steps on repeated identical successful inspections of one node within each
generation. All 64 actual replies parse, but none edits or explicitly finishes
a candidate. There are zero compiled designs, native worlds and scientist
replies; losses are null. Adapter intervals total 411.43 s, not overall wall
time. An independent stopped-writer audit checks 64 dispatches/replies,
523,598 prompt tokens and 2,112 completion tokens. The 4-slot budget is
charged without being relabelled four executed worlds.

\paragraph{Separately declared continuation.}
The next source keeps that failure intact and represents the last assistant
action and returned tool receipt as already-completed conversational turns.
Current remaining budget and repeated unchanged-inspection counts appear at
both ends. Legal repeated reads remain legal: this is a progress cue, not
a forced edit, automatic finish or operator-authored institution. The a2
protocol declares a separate four-slot/64-designer-POST maximum before any
new call. Its original world, fixed model, losses and own-history separation
remain unchanged. Source-conditioned engineering revisions are not a
controlled comparison, and their costs are not refunded or silently pooled.

\paragraph{Closed a2 outcome: automatic feedback with exact retention.}
All four scheduled native evaluations complete at immutable source
\texttt{51d9cbb}, with no technical failures
(Figure~\ref{fig:staged-native-v15}). The throughput path is $[-1,-1]$ and
the reviewed-production path is $[8,8]$. Each world measures $A=1$, $Q=4$
and $R=24$ under the unchanged definitions. Both G1 authoring prompts receive
their exact own completed G0 observation and scalar loss. Supplying this
feedback establishes the executable connection, not effective or causal use
of the feedback in the author's choice.

Every generation makes 15 inspections followed by one explicit valid finish.
All four finished candidates exactly retain the inherited 19-node, 27-wire
SystemSpec: zero authored edits, source changes, new factors, coordinates or
process/wiring changes. No objective-dependent institutional divergence or
new best is observed. Retention is a model action, not a host fallback, but
it is not new institutional invention. The 32 actual sandboxed code executions
belong to the disclosed developer-authored seed, not new local-Qwen code.

The four original-world evaluations contain 368 fresh scientist responses
(92 per world), with 1275.04 s of recorded scientist model-call time. The
designer records 64 known replies: 60 inspections and four finishes, 561,586
prompt tokens, 1,781 completion tokens and 989.67 s of adapter time. Overall
wall time is 39 min 19 s. Adapter, POST-transport and overall wall intervals
are different, partly overlapping measurements, not additional executions.
Two independent read-only audits agree byte-for-byte, preserve all 209 raw
files and match 242 replay-critical source blobs. They perform no new model
call or container execution. The a1 failure costs remain separate.

This operational loop uses the original fixed-weight researchers rather than
a numeric miniature. It does not establish useful invention, scientific
benefit, optimizer superiority, held-out generalization, automatic adoption
or a completed game. The new arbitrary-researcher-work API and later role/ABI
discovery interfaces remain separately SCRIPTED-tested; they are not used by
this frozen a2 designer. The four worlds share one development seed and the
same retained design, not four independent seeds or controlled institutional
contrasts.

The existing English cyberpunk Foundry displays the actual tool rail,
literal edits, validation errors and source/graph lineage. Failed generation,
valid finish and native execution are distinct statuses. Local file
observations are labelled provisional rather than independently audited
findings. Request validation and fresh exact compute consent remain separate
from viewing or importing the evidence. Original pixel city animation is
an interface representation, not evidence that an unexecuted world ran.
