\section{A finite native parameter comparator does not improve the incumbent}
\label{sec:native-numeric-comparator}
\subsection{An unchanged world, a deliberately narrower search}
We next run a parameter-only comparator against the closed planning archive.
This is a separately declared post-hoc comparator, not another execution of
its 14 worlds or a controlled causal intervention on design freedom.
Original native scientist, production and effect code is checked against
265 unchanged source files. Fixed Qwen3-8B scientists, the original corpus,
four years, world seed61001 and all original T/U measurements remain literal.
Only the already consumed integer reserve may vary from1 to60; code, nodes,
wiring, schedules and other parameters cannot change in this family.

The first tied best reference supplies each warm start: R2/advisory/reviewed
for T, and R7/assignment/no-review for U, each with reserve21. The existing
adaptive random search at seed68011 draws one initial uniform proposal per
objective, then bounded mutations around its best measured system, with
mutation scale0.2 and the existing decay. Three own slots per objective run
in order T0,U0,U1,T1,T2,U2. No designer LLM or readiness call generates these
numerical proposals. Eight reference outcomes and the six earlier free-program
slots are reused transparently, not counted as fresh worlds or independent
optimizer histories. Unknown or failed observations would remain null, with
no repair, refill or invented penalty.

The original presentation-dependent resource coordinator stopped without
starting this experiment. A separate prospective dispatcher starts the same
previously unused plan only after checking its exact original source/bank,
the other study's stop, retired processes and two fresh empty-backend
observations30 seconds apart. This is not resumption of the stopped study:
its unknown response remains unknown and its partial feedback is not used.

\subsection{Improving an own-output path is not improving the known solution}
All six new worlds complete and both original-source cold audits, cost
projections and complete report exports agree. The best-own T path is flat
at$-12$, and its earliest selected submission is T0, with all three own ties.
The best-own U path falls from$-8$ to$-9.3333$ to$-10$, selecting U2. Neither
reaches the corresponding original warm start. The best-known path, which
retains completed references, therefore remains T=$-18$/U=$-13.3333$.
Own-only selection and the optimization incumbent are different readouts;
we do not replace a worse generated output with a reference and call that
reference an invented improvement. Nor do these six trials establish that
reserve21 is globally optimal over the declared60 values.

The earlier free-program own submissions attain those strong reference
losses. That is an observed package-level comparison, not an intrinsic
advantage of program search: information, interfaces, generation expense and
design families differ, and this comparator was designed after the pilot.
One history per objective and one reused world seed cannot rank optimization
methods in expectation. A larger run of the same comparison would not by
itself isolate those confounds.

\paragraph{Literal paths and observed experience.}
T0/reserve3 and T1/reserve10 each contain133 complete scientist requests.
Their ordered full model-input payloads and literal response choices match;
all four actual allocation returns in each run request no transfers.
The provider envelopes remain different and are retained separately. This
checks these two observed histories, not global equivalence of the policies
or permission to share future world jobs. The complete all-world input-class
readout remains a separate audit-bound analysis, not an assumption inferred
from matching scalar losses.

\paragraph{Measured expense and boundary.}
The six-world scientific interval spans about79 minutes7 seconds, including
its native scientist and observer phases. Recorded scientist usage comprises
664 responses,704,991 prompt tokens and67,549 completion tokens, with no
wire input lacking a committed reply. The common observer adds93 physical
critic requests,44,481 input tokens and13,766 output tokens; content cache hits
are not extra independent ratings. Six ordinary scientist role loads are
recorded separately. This is end-to-end local elapsed time, not a dedicated
model-speed benchmark, GPU FLOP estimate, energy measurement or dollar cost.
The later audits/reports are outside that scientific interval. No unused
evaluation condition is selected or run by this comparator.
