\section{Changing observation and action timing in the native world}
\label{sec:native-workflow-controls}
\subsection{An operated structural slice, not a replacement researcher world}
The preceding parameter study leaves an important axis untested: when existing
institutions observe the world and act on it. We therefore construct a
structural-only search domain over the same native scientist world. Existing
mechanism source, parameters, actor population, corpus, Qwen3-8B scientists,
loss definitions and four-year horizon remain fixed. Phase assignments and
connections among existing typed ports may change. This controlled slice does
not exhaust the framework's code-defined mechanism and composition freedom.

The original assignment/reserve-21/reviewer-free reference, R7, supplies the
initial graph. A strong developer control moves liquidity allocation, its
effect consumer and research-cost collection after funding. Three phases and
five connections change, without replacing existing mechanism implementations.
The proposed experiment allows six own submissions, three under each of T and
U, with both controls measured in the same reused development condition,
seed 61001. It does not require novel wires, participation preservation or
improvement for a candidate to be valid. Such requirements would change the
declared optimization problem.

This experiment does \emph{not} normally close. Both reference cells complete;
two model-authored proposals fail before a native world, and the next
history-bearing readiness check returns an invalid graph. Two consumed own
slots, zero own native worlds and no final selection are retained. Remaining
slots are not refilled. The cause is not a missing scientist response in this
attempt: the relevant designer replies have known final completion signals.

\subsection{A completed-reference contrast within a stopped experiment}
The completed cells remain analyzable without fabricating whole-study closure.
A separately scoped reader runs against the exact original scientific source,
checks checkpoints, scientist replies, code-execution receipts, fixed-content
critic outputs, declared losses and reconciled resource ledgers. Two executions
produce byte-identical reports, retaining all 333 original raw files and an
exact closure of 304 source files. This is repeatable analysis of the same two
observations, not independent experimental replication. The missing original
whole-study observer-audit file is not manufactured, and these reports cannot
supply a selection-fixed evaluation prerequisite.

\paragraph{Why this is not a pure cost-order effect.}
Moving a stage changes the available observation snapshot. The legal hand
graph consequently reroutes inputs as well as changing relative timing.
Original funding-stage summaries occur before later mutations in the hand
workflow and cannot be read as common end-of-year stocks. The native funding
cycle's existing deactivation rule and its truthy-zero exception remain
literal; they are not repaired to make the comparison cleaner. End-year
ledgers do not recover within-year minima or isolate the moment of attrition.
Thus Table~\ref{tab:workflow-completed-controls} is an operated joint
timing/information-routing contrast, not an isolated causal estimate of
funding-before-fees. Four legal static timing corners have been constructed,
but no factorial worlds are executed by this analysis.

Both T and U prefer the same hand control here. The contrast therefore
demonstrates a consequential additional design axis, not objective-dependent
autonomous discovery, an optimum, stable superiority or validated real-world
science policy. Existing institutional-intervention precedents already
motivate studying such effects; our main scientific question still requires
the objective-to-generated-system comparison, rather than claiming timing
interventions themselves as a priority contribution.

\subsection{Designer execution remains a separate empirical boundary}
The two rejected own proposals respectively duplicate a graph connection and
use an unexpected output property. The next readiness reply duplicates edges
and leaves required inputs unconnected. Original public replay reconstructs
those exact failures. A copy diagnostic is not a dispatch veto: the graphs
are invalid under the unchanged executable domain. No scientific losses are
assigned to unexecuted proposals.

A separately declared four-call local diagnostic varies only JSON Schema
formatting and the model's thinking switch on the retained failed-history
frame. Schema/nonthinking still returns an invalid graph; both thinking
settings return valid directed calibration controls. The predeclared
technical priority chooses schema/thinking, not an objective score or a
novelty test. Its one free-design call reaches the 8,192-output-token limit
with 29,444 thinking characters but zero final-content characters. The finish
reason is \code{length}, not an HTTP timeout or completion unknown. We do not
parse a graph from thinking text or count directed calibration as free design.
The diagnostic consumes 103,439 input and 13,110 output tokens including
thinking, without any new scientist world or loss observation.

These observations separate three requirements: a readable interface control,
a complete free submission, and an effective institution after native
execution. Neither a valid copied control nor a schema-accepted HTTP call
establishes the latter two. The finite followup changes only the output
allowance to 16,384 on the same free frame. This one call does return final
JSON: 23,862 input and 12,563 output tokens, with the earlier thinking text as
an exact prefix. Its six phase edits nevertheless place selection at phase 40
before four connected producers at phases 70, 100, 110 and 120. The unchanged
compiler rejects it. Its prose about retaining a valid order is not evidence
of what the literal graph implements. The capacity probe ends without repair,
further allowance increases, a production certificate or scientific execution.
This technical work is reported as an empirical limit,
not the main institutional-optimization contribution or proof that a model
can never invent an effective system.
