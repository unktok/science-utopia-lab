# Main-paper outline: objective-conditioned scientific institutions

Working claim outline,2026-11-07. This is not a submitted or accepted paper.
The [research plan](../research/publication/plan.md) controls required evidence.
The existing long main.tex remains a historical working draft until rewritten;
its NeurIPS2025 style is not a claim of compliance with a future venue.
The new [short submission draft](submission.tex) implements this structure;
its pending empirical section is filled only after original-source audit.

## Narrative

1. **Question and gap**: an explicit objective selects an organizing scientific
   system; contrast intervention analysis and fixed-menu policy tuning.
2. **Problem and design space**: fixed researcher weights, stochastic native
   evaluator, executable SystemSpec; parameters/rules/mechanisms/wiring/processes.
3. **Search and experimental protocol**: existing interchangeable proposers,
   declared loss, comparable information and compute, separate validity/evaluation.
4. **Results**: objective-conditioned paths, parameter/free-design contrasts,
   feedback ablation and cross-objective selected-system evaluation. Report ties
   and negative results; these experiments are not all complete yet.
5. **Mechanistic analysis**: trace changed institutions to actual downstream
   researcher inputs/actions. Explain proxy incentives, costs and failure modes.
6. **Limits and implications**: no universal scientific-quality metric, small
   development worlds, simulator/model dependence, conditional gradient scope.

## Core figures

- Concept: what changes versus how search operates, with original-world containment.
- Search paths and costs: all trials/nulls, best-so-far, shared history separately.
- Cross-objective matrix: objective-selected systems, all ties, common evaluation.
- Institution difference: graph/source/process changes plus actual effect traces.
- Freedom/feedback ablations; uncertainty only when independent repetitions exist.

UI illustrates the same canonical evidence and belongs in artifact/demo material
unless a separate user-study claim is made. Detailed API, renderer corrections,
source bindings and historical campaigns belong in the appendix/repository.

## Claims not presently supported

Reliable local autonomous improvement, superiority of free design over matched
parameter tuning, superiority of gradient methods, full-world/LLM Jacobians,
inventor self-improvement, real scientific-policy benefit and broad generalization.
New evidence may change this list; prose alone must not.
